我有一套很复杂的计算逻辑，需要调用很多个方法，我想可视化一下。想着弄一个计算引擎平台。可以展示节点，拖动节点连线，执行flow，新建flow，保存flow，节点可以修改名称，描述等。然后节点主要有三个类型，输入 输出 计算。输入节点可以支持json，excel，htttp db等 现在最小版本只需要json。输出节点和输入节点类似。计算节点可以有多个输入节点，也可以有多个输出节点。最好弄一个注解，可以把现有的方法直接变成节点。左侧展示节点，中间展示画布，点击画布上节点，可以修改节点一些配置，比如参数，名称，描述等。节点输入输出连线都是一个端口，但是可以分出不同的线来连接其他节点。我用的springboot3 vue3 typescript。这个计算平台可以可视化现有的一套flow计算逻辑，也可以根据节点新建flow。先帮我实现一个最小版本。

# Flow 计算引擎平台 — 最小可用版本

下面给你一套完整可跑的最小版本，技术栈完全按你的要求：**Spring Boot 3 + Vue 3 + TypeScript**。

## 一、整体设计

**核心思路：**

1. **图数据结构**：画布本质是一张图 `{ nodes, edges }`，前端用 [Vue Flow](https://vueflow.dev/) 渲染，后端存同一份 JSON，执行时解析它
2. **注解驱动节点**：`@FlowNode` 注解打在任意 Spring Bean 的方法上，启动时自动扫描注册成节点，左侧节点库自动出现
3. **执行引擎**：拓扑排序（Kahn）→ 按序执行 → 上游输出沿边流向下游输入，天然支持环检测、一输入多输出、多输入汇聚
4. **单端口多连线**：节点只有一个输入/输出端口，Vue Flow 原生支持一个端口拉出任意多条边

**参数注入规则**（注解方法签名很灵活）：

| 方法参数类型 | 引擎注入的内容 |
|---|---|
| `Map<String,Object>` | 节点在画布上配置的参数 |
| `List<Object>` | 所有上游节点的输出列表 |
| `NodeContext` | 完整上下文（id/名称/配置/输入） |
| 其他类型 | 第一个上游输入 |

### registry/NodeRegistry.java —— 注解扫描与反射调用

```java
package com.example.flowengine.registry;

import com.example.flowengine.annotation.ConfigField;
import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.engine.NodeContext;
import com.example.flowengine.model.NodeDefinition;
import com.example.flowengine.model.NodeDefinition.ConfigFieldDef;
import jakarta.annotation.PostConstruct;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.context.ApplicationContext;
import org.springframework.stereotype.Component;
import org.springframework.util.ClassUtils;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Modifier;
import java.util.*;

@Component
public class NodeRegistry {

    private static final Logger log = LoggerFactory.getLogger(NodeRegistry.class);

    private record RegisteredNode(NodeDefinition definition, Object bean, Method method) {}

    private final ApplicationContext applicationContext;
    private final Map<String, RegisteredNode> nodes = new LinkedHashMap<>();

    public NodeRegistry(ApplicationContext applicationContext) {
        this.applicationContext = applicationContext;
    }

    /** 启动时扫描所有 Bean 方法上的 @FlowNode */
    @PostConstruct
    void scan() {
        for (String beanName : applicationContext.getBeanDefinitionNames()) {
            Object bean;
            try {
                bean = applicationContext.getBean(beanName);
            } catch (Exception e) {
                continue;
            }
            Class<?> targetClass = ClassUtils.getUserClass(bean.getClass());
            if (skip(targetClass)) continue;

            for (Method method : targetClass.getMethods()) {
                FlowNode ann = method.getAnnotation(FlowNode.class);
                if (ann == null || Modifier.isStatic(method.getModifiers())) continue;

                String id = beanName + "." + method.getName();
                if (nodes.containsKey(id)) {
                    throw new IllegalStateException("节点ID重复: " + id);
                }
                method.setAccessible(true);

                List<ConfigFieldDef> fields = Arrays.stream(ann.fields())
                        .map(f -> new ConfigFieldDef(
                                f.key(),
                                f.label().isEmpty() ? f.key() : f.label(),
                                f.type().name().toLowerCase(),
                                f.defaultValue()))
                        .toList();

                NodeDefinition def = new NodeDefinition(
                        id, ann.name(), ann.description(), ann.type(), ann.category(), fields);
                nodes.put(id, new RegisteredNode(def, bean, method));
                log.info("注册流程节点: {} ({})", ann.name(), id);
            }
        }
    }

    private boolean skip(Class<?> clazz) {
        String name = clazz.getName();
        return name.startsWith("org.springframework") || name.startsWith("java.")
                || name.startsWith("jdk.") || name.startsWith("com.sun")
                || name.contains("$$SpringCGLIB$$");
    }

    public List<NodeDefinition> getDefinitions() {
        return nodes.values().stream().map(RegisteredNode::definition).toList();
    }

    public NodeDefinition getDefinition(String id) {
        RegisteredNode n = nodes.get(id);
        return n == null ? null : n.definition();
    }

    /** 反射执行节点方法 */
    public Object execute(String defId, NodeContext context) throws Exception {
        RegisteredNode n = nodes.get(defId);
        if (n == null) throw new IllegalArgumentException("未找到节点定义: " + defId);
        try {
            return n.method().invoke(n.bean(), resolveArgs(n.method(), context));
        } catch (InvocationTargetException e) {
            throw e.getCause() instanceof Exception ex ? ex : e;
        }
    }

    /** 按参数类型自动注入：Map→配置，List→全部上游输入，其他→第一个上游输入 */
    private Object[] resolveArgs(Method method, NodeContext ctx) {
        Class<?>[] types = method.getParameterTypes();
        Object[] args = new Object[types.length];
        for (int i = 0; i < types.length; i++) {
            Class<?> t = types[i];
            if (NodeContext.class.isAssignableFrom(t)) args[i] = ctx;
            else if (Map.class.isAssignableFrom(t)) args[i] = ctx.config() == null ? Map.of() : ctx.config();
            else if (List.class.isAssignableFrom(t)) args[i] = ctx.inputs() == null ? List.of() : ctx.inputs();
            else args[i] = (ctx.inputs() == null || ctx.inputs().isEmpty()) ? null : ctx.inputs().get(0);
        }
        return args;
    }
}
```

### engine/FlowExecutionEngine.java —— 执行引擎

```java
package com.example.flowengine.engine;

import com.example.flowengine.model.*;
import com.example.flowengine.registry.NodeRegistry;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.stream.Collectors;

@Service
public class FlowExecutionEngine {

    private final NodeRegistry registry;

    public FlowExecutionEngine(NodeRegistry registry) {
        this.registry = registry;
    }

    public record NodeTrace(String nodeId, String nodeName, String defName, String status,
                            long durationMs, Object output, String error) {}

    public record ExecutionResult(boolean success, String error, List<NodeTrace> traces,
                                  Map<String, Object> outputs, long durationMs) {}

    public ExecutionResult execute(FlowGraph graph) {
        long start = System.currentTimeMillis();
        List<GraphNode> nodes = graph == null || graph.nodes() == null ? List.of() : graph.nodes();
        List<GraphEdge> edges = graph == null || graph.edges() == null ? List.of() : graph.edges();
        List<NodeTrace> traces = new ArrayList<>();

        if (nodes.isEmpty()) {
            return new ExecutionResult(false, "流程中没有节点", traces, Map.of(), 0);
        }

        Map<String, GraphNode> nodeById = nodes.stream()
                .collect(Collectors.toMap(GraphNode::id, n -> n));
        for (GraphEdge e : edges) {
            if (!nodeById.containsKey(e.source()) || !nodeById.containsKey(e.target())) {
                return new ExecutionResult(false, "连线引用了不存在的节点: " + e.id(), traces, Map.of(), 0);
            }
        }

        // 邻接关系 + 入度
        Map<String, List<String>> incoming = new HashMap<>();
        Map<String, Integer> indegree = new HashMap<>();
        nodes.forEach(n -> indegree.put(n.id(), 0));
        for (GraphEdge e : edges) {
            incoming.computeIfAbsent(e.target(), k -> new ArrayList<>()).add(e.source());
            indegree.merge(e.target(), 1, Integer::sum);
        }

        // Kahn 拓扑排序
        Deque<String> queue = new ArrayDeque<>();
        nodes.forEach(n -> { if (indegree.get(n.id()) == 0) queue.add(n.id()); });
        List<String> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            String id = queue.poll();
            order.add(id);
            for (GraphEdge e : edges) {
                if (e.source().equals(id) && indegree.merge(e.target(), -1, Integer::sum) == 0) {
                    queue.add(e.target());
                }
            }
        }
        if (order.size() != nodes.size()) {
            return new ExecutionResult(false, "流程中存在循环依赖，请检查连线", traces, Map.of(), 0);
        }

        Map<String, Object> outputs = new HashMap<>();
        Map<String, String> status = new HashMap<>();
        Map<String, Object> finalOutputs = new LinkedHashMap<>();
        boolean allSuccess = true;

        for (String id : order) {
            GraphNode node = nodeById.get(id);
            FlowNodeData data = node.data();
            String nodeName = data != null && data.name() != null ? data.name() : id;
            String defName = data != null ? data.defName() : null;
            List<String> sources = incoming.getOrDefault(id, List.of());

            // 上游失败则跳过
            if (!sources.isEmpty() && sources.stream().anyMatch(s -> !"SUCCESS".equals(status.get(s)))) {
                status.put(id, "SKIPPED");
                traces.add(new NodeTrace(id, nodeName, defName, "SKIPPED", 0, null, "上游节点未成功执行"));
                allSuccess = false;
                continue;
            }

            NodeDefinition def = data == null ? null : registry.getDefinition(data.defId());
            if (def == null) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED", 0, null,
                        "未找到节点定义: " + (data == null ? "?" : data.defId())));
                continue;
            }

            List<Object> inputs = sources.stream().map(outputs::get).collect(Collectors.toList());
            long t0 = System.currentTimeMillis();
            try {
                Map<String, Object> config = data.config() == null ? Map.of() : data.config();
                Object result = registry.execute(def.id(), new NodeContext(id, nodeName, config, inputs));
                outputs.put(id, result);
                status.put(id, "SUCCESS");
                traces.add(new NodeTrace(id, nodeName, defName, "SUCCESS",
                        System.currentTimeMillis() - t0, result, null));
                if (def.type() == NodeType.OUTPUT) {
                    finalOutputs.put(nodeName, result);
                }
            } catch (Exception ex) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED",
                        System.currentTimeMillis() - t0, null, message(ex)));
            }
        }

        return new ExecutionResult(allSuccess, allSuccess ? null : "部分节点执行失败",
                traces, finalOutputs, System.currentTimeMillis() - start);
    }

    private String message(Throwable t) {
        return t.getMessage() == null ? t.getClass().getSimpleName() : t.getMessage();
    }
}
```

```java
package com.example.flowengine.nodes;

import com.example.flowengine.annotation.ConfigField;
import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.model.NodeType;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

@Component
public class BuiltinNodes {

    private final ObjectMapper objectMapper = new ObjectMapper();

    // ---------- 输入节点（最小版本只做 JSON，后续可加 Excel/HTTP/DB） ----------

    @FlowNode(name = "JSON输入", type = NodeType.INPUT, category = "输入",
            description = "将配置的 JSON 文本解析为数据对象",
            fields = @ConfigField(key = "jsonText", label = "JSON内容",
                    type = ConfigField.FieldType.TEXTAREA, defaultValue = "{}"))
    public Object jsonInput(Map<String, Object> config) throws Exception {
        String text = asString(config.get("jsonText"));
        if (text == null || text.isBlank()) return Map.of();
        return objectMapper.readValue(text, Object.class);
    }

    // ---------- 输出节点 ----------

    @FlowNode(name = "JSON输出", type = NodeType.OUTPUT, category = "输出",
            description = "将上游结果序列化为 JSON 字符串")
    public Object jsonOutput(List<Object> inputs) throws Exception {
        Object payload = inputs.size() == 1 ? inputs.get(0) : inputs;
        return objectMapper.writerWithDefaultPrettyPrinter().writeValueAsString(payload);
    }

    // ---------- 计算节点 ----------

    @FlowNode(name = "字段提取", category = "计算",
            description = "从 Map 或 Map 列表中按 key 提取字段",
            fields = @ConfigField(key = "field", label = "字段名"))
    public Object extractField(List<Object> inputs, Map<String, Object> config) {
        String field = asString(config.get("field"));
        if (field == null || field.isBlank()) throw new IllegalArgumentException("缺少参数 field");
        List<Object> result = new ArrayList<>();
        inputs.forEach(in -> collect(in, field, result));
        return result.size() == 1 ? result.get(0) : result;
    }

    private void collect(Object value, String field, List<Object> out) {
        if (value instanceof Map<?, ?> map) out.add(map.get(field));
        else if (value instanceof List<?> list) list.forEach(o -> collect(o, field, out));
    }

    @FlowNode(name = "数值求和", category = "计算", description = "对所有输入中的数值求和（支持多个输入汇聚）")
    public Object sum(List<Object> inputs) {
        double[] total = {0};
        inputs.forEach(v -> sumInto(v, total));
        return total[0] % 1 == 0 ? (long) total[0] : total[0];
    }

    private void sumInto(Object value, double[] total) {
        if (value instanceof Number n) total[0] += n.doubleValue();
        else if (value instanceof List<?> list) list.forEach(o -> sumInto(o, total));
        else if (value instanceof Map<?, ?> map) map.values().forEach(v -> sumInto(v, total));
    }

    @FlowNode(name = "常量", category = "计算", description = "无需输入，输出一个配置的常量值",
            fields = @ConfigField(key = "value", label = "常量值",
                    type = ConfigField.FieldType.NUMBER, defaultValue = "0"))
    public Object constant(Map<String, Object> config) {
        return config.get("value");
    }

    private String asString(Object o) { return o == null ? null : String.valueOf(o); }
}
```

### repository/FlowRepository.java —— 内存存储 + 种子数据

```java
package com.example.flowengine.repository;

import com.example.flowengine.model.*;
import org.springframework.stereotype.Repository;

import java.time.Instant;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

/** 最小版本用内存存储，后续可替换为 JPA + 数据库 */
@Repository
public class FlowRepository {

    private final Map<String, Flow> store = new ConcurrentHashMap<>();

    public FlowRepository() {
        seed();
    }

    public List<Flow> findAll() {
        return store.values().stream()
                .sorted(Comparator.comparing(Flow::getUpdatedAt).reversed()).toList();
    }

    public Optional<Flow> findById(String id) { return Optional.ofNullable(store.get(id)); }

    public Flow save(Flow flow) {
        flow.setUpdatedAt(Instant.now());
        store.put(flow.getId(), flow);
        return flow;
    }

    public void delete(String id) { store.remove(id); }

    /** 种子示例：订单金额汇总（含多输入汇聚演示） */
    private void seed() {
        Map<String, Object> jsonConfig = new HashMap<>();
        jsonConfig.put("jsonText", """
                {
                  "order": "DEMO-001",
                  "items": [
                    {"name": "键盘", "amount": 199},
                    {"name": "鼠标", "amount": 99},
                    {"name": "显示器", "amount": 1299}
                  ]
                }
                """);

        // 注意：defId = beanName + "." + 方法名
        FlowGraph graph = new FlowGraph(List.of(
                node("n1", NodeType.INPUT,   40, 180, data("builtinNodes.jsonInput",   NodeType.INPUT,   "JSON输入", "订单数据", "演示输入", jsonConfig)),
                node("n2", NodeType.COMPUTE, 280, 80,  data("builtinNodes.extractField", NodeType.COMPUTE, "字段提取", "提取items", "", Map.of("field", "items"))),
                node("n3", NodeType.COMPUTE, 520, 80,  data("builtinNodes.extractField", NodeType.COMPUTE, "字段提取", "提取amount", "", Map.of("field", "amount"))),
                node("n5", NodeType.COMPUTE, 280, 320, data("builtinNodes.constant",   NodeType.COMPUTE, "常量", "运费", "", Map.of("value", 10))),
                node("n4", NodeType.COMPUTE, 760, 200, data("builtinNodes.sum",        NodeType.COMPUTE, "数值求和", "总金额", "", Map.of())),
                node("n6", NodeType.OUTPUT,  1000, 200, data("builtinNodes.jsonOutput", NodeType.OUTPUT, "JSON输出", "结果输出", "", Map.of()))
        ), List.of(
                edge("n1", "n2"), edge("n2", "n3"), edge("n3", "n4"),
                edge("n5", "n4"), edge("n4", "n6")
        ));

        Flow flow = new Flow();
        flow.setId("demo");
        flow.setName("示例：订单金额汇总");
        flow.setDescription("JSON输入 → 字段提取 → 求和（与运费常量汇聚）→ JSON输出");
        flow.setGraph(graph);
        flow.setUpdatedAt(Instant.now());
        store.put(flow.getId(), flow);
    }

    private static GraphNode node(String id, NodeType type, double x, double y, FlowNodeData data) {
        return new GraphNode(id, "flow-node", data, Map.of("x", x, "y", y));
    }

    private static FlowNodeData data(String defId, NodeType type, String defName,
                                     String name, String description, Map<String, Object> config) {
        return new FlowNodeData(defId, type, defName, name, description, config);
    }

    private static GraphEdge edge(String source, String target) {
```

```java
package com.example.flowengine.service;

import com.example.flowengine.model.Flow;
import com.example.flowengine.model.FlowGraph;
import com.example.flowengine.repository.FlowRepository;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.web.server.ResponseStatusException;

import java.time.Instant;
import java.util.List;
import java.util.UUID;

@Service
public class FlowService {

    private final FlowRepository repository;

    public FlowService(FlowRepository repository) {
        this.repository = repository;
    }

    public record FlowSummary(String id, String name, String description, Instant updatedAt) {}

    public List<FlowSummary> list() {
        return repository.findAll().stream()
                .map(f -> new FlowSummary(f.getId(), f.getName(), f.getDescription(), f.getUpdatedAt()))
                .toList();
    }

    public Flow get(String id) {
        return repository.findById(id)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "流程不存在: " + id));
    }

    public Flow create(String name, String description, FlowGraph graph) {
        Flow flow = new Flow();
        flow.setId(UUID.randomUUID().toString().replace("-", "").substring(0, 12));
        flow.setName(name == null || name.isBlank() ? "未命名流程" : name);
        flow.setDescription(description);
        flow.setGraph(graph == null ? new FlowGraph(List.of(), List.of()) : graph);
        return repository.save(flow);
    }

    public Flow update(String id, String name, String description, FlowGraph graph) {
        Flow flow = get(id);
        if (name != null && !name.isBlank()) flow.setName(name);
        flow.setDescription(description);
        if (graph != null) flow.setGraph(graph);
        return repository.save(flow);
    }

    public void delete(String id) {
        get(id);
        repository.delete(id);
    }
}
```

```vue
<script setup lang="ts">
import { nextTick } from 'vue'
import { VueFlow, useVueFlow, type Connection, type GraphNode } from '@vue-flow/core'
import { Background } from '@vue-flow/background'
import { Controls } from '@vue-flow/controls'
import FlowNode from './FlowNode.vue'
import type { FlowGraph, FlowNodeData, NodeDefinition } from '../types'

const emit = defineEmits<{ (e: 'node-select', node: GraphNode | null): void }>()

const nodeTypes = { 'flow-node': FlowNode }

const {
  addNodes, addEdges, setNodes, setEdges, removeNodes,
  getNodes, getEdges, screenToFlowCoordinate, fitView
} = useVueFlow()

let seq = 0

/** 从节点定义创建画布节点 */
function addNode(def: NodeDefinition, at?: { x: number; y: number }) {
  const id = `n_${Date.now()}_${seq++}`
  const config: Record<string, any> = {}
  def.fields?.forEach(f => {
    config[f.key] = f.defaultValue ?? ''
  })
  const data: FlowNodeData = {
    defId: def.id,
    nodeType: def.type,
    defName: def.name,
    name: def.name,
    description: def.description,
    config
  }
  addNodes({
    id,
    type: 'flow-node',
    position: at ?? { x: 220 + (seq % 6) * 36, y: 140 + (seq % 6) * 36 },
    data
  })
}

function onDrop(event: DragEvent) {
  const raw = event.dataTransfer?.getData('application/flow-node')
  if (!raw) return
  const def: NodeDefinition = JSON.parse(raw)
  const position = screenToFlowCoordinate({ x: event.clientX, y: event.clientY })
  addNode(def, position)
}

function onConnect(conn: Connection) {
  const dup = getEdges.value.some(e => e.source === conn.source && e.target === conn.target)
  if (dup || !conn.source || !conn.target) return
  addEdges({
    id: `e_${conn.source}_${conn.target}_${Date.now()}`,
    source: conn.source,
    target: conn.target,
    type: 'smoothstep'
  })
}

function onSelectionChange(params: { nodes: GraphNode[] }) {
  emit('node-select', params.nodes.length ? params.nodes[0] : null)
}

/** 序列化当前画布 */
function getGraph(): FlowGraph {
  return {
    nodes: getNodes.value.map(n => ({
      id: n.id,
      type: n.type,
      position: { x: n.position.x, y: n.position.y },
      data: n.data
    })),
    edges: getEdges.value.map(e => ({ id: e.id, source: e.source, target: e.target }))
  }
}

function loadGraph(graph: FlowGraph) {
  setNodes((graph?.nodes ?? []).map(n => ({
    ...n,
    type: 'flow-node',
    data: { ...n.data, config: n.data?.config ?? {} }
  })))
  setEdges((graph?.edges ?? []).map(e => ({ ...e, type: 'smoothstep' })))
  nextTick(() => fitView({ padding: 0.2 }))
}

function clear() {
  setNodes([])
  setEdges([])
}

function applyStatus(map: Record<string, 'success' | 'failed' | 'skipped'>) {
  getNodes.value.forEach(n => {
    ;(n.data as FlowNodeData).status = map[n.id]
  })
}

function clearStatus() {
  getNodes.value.forEach(n => {
    delete (n.data as FlowNodeData).status
  })
```

## 五、如何把你现有的方法接入成节点

这是这个方案最核心的部分——**在现有方法上加一个注解即可**：

```java
@Service
public class RiskRules {

    @FlowNode(
        name = "风控评分",
        category = "风控",
        description = "根据订单数据计算风控分",
        fields = @ConfigField(key = "threshold", label = "阈值",
                type = ConfigField.FieldType.NUMBER, defaultValue = "80")
    )
    public Object score(List<Object> inputs, Map<String, Object> config) {
        double threshold = Double.parseDouble(String.valueOf(config.get("threshold")));
        // ... 你现有的计算逻辑，原封不动
        return result;
    }
}
```

重启后端，左侧节点库自动出现「风控评分」，画布上可配置阈值参数。规则回顾：

- 参数里写 `Map` → 收到画布上配置的参数
- 参数里写 `List` → 收到所有上游节点的输出
- 注解的 `fields` → 前端自动渲染配置表单，不用写一行前端代码
- 节点 id 规则为 `beanName.方法名`，需要改名可用 `@Component("xxx")`

### ASSISTANT
有的，这个需求很合理——工作流引擎里一般叫 **FlowContext / 流程上下文**。我现在给你加上。先说清楚一个关键点：

> **执行顺序是由图决定的**。如果 C 和 A 没连线，引擎不知道要先执行 A，C 可能先跑，此时去拿 A 的数据就是空的。所以除了提供 `FlowContext`，还要配一个**隐式依赖 `dependsOn`**：不传数据、不画线，只保证执行顺序。

设计如下：

- `FlowContext`：任意节点方法里注入，`getOutput("节点ID或名称")` 拿任意已执行节点的输出；另有 `put/get` 提供流程级共享变量
- `config.dependsOn`：节点配置里写节点ID/名称（逗号分隔），引擎自动加"只排序、不传数据"的虚拟边
- 新增内置节点「**读取上下文**」：画布上不写代码也能用这个能力

## 1. 新增 `engine/FlowContext.java`

```java
package com.example.flowengine.engine;

import java.util.Map;

/**
 * 流程执行上下文：任意节点可从这里读取其他已执行节点的输出（无需连线）。
 * 在 @FlowNode 方法参数里声明 FlowContext 即可自动注入。
 */
public interface FlowContext {

    String executionId();

    String flowName();

    /** 按节点ID或节点名称获取输出；找不到或尚未执行时抛异常并给出提示 */
    Object getOutput(String nodeIdOrName);

    Object getOutputOrDefault(String nodeIdOrName, Object defaultValue);

    boolean hasOutput(String nodeIdOrName);

    /** 所有已执行节点的输出（key 为节点ID） */
    Map<String, Object> allOutputs();

    // ---- 流程级共享变量：不依赖图结构的跨节点传值 ----
    void put(String key, Object value);

    Object get(String key);
```

```java
package com.example.flowengine.engine;

import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.NoSuchElementException;
import java.util.concurrent.ConcurrentHashMap;

public class DefaultFlowContext implements FlowContext {

    private final String executionId;
    private final String flowName;
    private final Map<String, String> nameToId;          // 节点名称 -> 节点ID
    private final Map<String, Object> outputs = new LinkedHashMap<>();
    private final Map<String, Object> variables = new ConcurrentHashMap<>();

    public DefaultFlowContext(String executionId, String flowName, Map<String, String> nameToId) {
        this.executionId = executionId;
        this.flowName = flowName;
        this.nameToId = Map.copyOf(nameToId);
    }

    /** 引擎内部调用：写入节点输出 */
    void putOutput(String nodeId, Object output) {
        outputs.put(nodeId, output);
    }

    private String resolveId(String nodeIdOrName) {
        if (nodeIdOrName == null) return null;
        if (outputs.containsKey(nodeIdOrName)) return nodeIdOrName;
        return nameToId.get(nodeIdOrName);
    }

    @Override
    public String executionId() { return executionId; }

    @Override
    public String flowName() { return flowName; }

    @Override
    public Object getOutput(String nodeIdOrName) {
        String id = resolveId(nodeIdOrName);
        if (id == null || !outputs.containsKey(id)) {
            throw new NoSuchElementException("无法获取节点[" + nodeIdOrName + "]的输出：节点不存在或尚未执行。"
                    + "若两个节点之间没有连线，请在读取方节点配置中设置 dependsOn=\"" + nodeIdOrName + "\" 来保证执行顺序");
        }
        return outputs.get(id);
    }

    @Override
    public Object getOutputOrDefault(String nodeIdOrName, Object defaultValue) {
        String id = resolveId(nodeIdOrName);
        return id != null && outputs.containsKey(id) ? outputs.get(id) : defaultValue;
    }

    @Override
    public boolean hasOutput(String nodeIdOrName) {
        String id = resolveId(nodeIdOrName);
        return id != null && outputs.containsKey(id);
    }

    @Override
    public Map<String, Object> allOutputs() {
        return Collections.unmodifiableMap(outputs);
    }

    @Override
    public void put(String key, Object value) { variables.put(key, value); }

    @Override
    public Object get(String key) { return variables.get(key); }

    @Override
    public Object getOrDefault(String key, Object defaultValue) {
        return variables.getOrDefault(key, defaultValue);
    }
}
```

## 4. 修改 `engine/FlowExecutionEngine.java`（整个替换 `execute` 部分）

核心变化：**数据边**（决定输入）和**顺序边**（数据边 + dependsOn 隐式边，只决定执行顺序）拆开。

```java
package com.example.flowengine.engine;

import com.example.flowengine.model.*;
import com.example.flowengine.registry.NodeRegistry;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.stream.Collectors;

@Service
public class FlowExecutionEngine {

    /** 节点配置中隐式依赖的 key */
    public static final String DEPENDS_ON_KEY = "dependsOn";

    private final NodeRegistry registry;

    public FlowExecutionEngine(NodeRegistry registry) {
        this.registry = registry;
    }

    public record NodeTrace(String nodeId, String nodeName, String defName, String status,
                            long durationMs, Object output, String error) {}

    public record ExecutionResult(boolean success, String error, List<NodeTrace> traces,
                                  Map<String, Object> outputs, long durationMs) {}

    public ExecutionResult execute(FlowGraph graph) {
        return execute(graph, null);
    }

    public ExecutionResult execute(FlowGraph graph, String flowName) {
        long start = System.currentTimeMillis();
        List<GraphNode> nodes = graph == null || graph.nodes() == null ? List.of() : graph.nodes();
        List<GraphEdge> edges = graph == null || graph.edges() == null ? List.of() : graph.edges();
        List<NodeTrace> traces = new ArrayList<>();

        if (nodes.isEmpty()) {
            return new ExecutionResult(false, "流程中没有节点", traces, Map.of(), 0);
        }

        Map<String, GraphNode> nodeById = nodes.stream()
                .collect(Collectors.toMap(GraphNode::id, n -> n));
        for (GraphEdge e : edges) {
            if (!nodeById.containsKey(e.source()) || !nodeById.containsKey(e.target())) {
                return new ExecutionResult(false, "连线引用了不存在的节点: " + e.id(), traces, Map.of(), 0);
            }
        }

        // 节点名称索引：支持按名称引用节点
        Map<String, String> nameToId = new HashMap<>();
        for (GraphNode n : nodes) {
            FlowNodeData d = n.data();
            if (d != null && d.name() != null && !d.name().isBlank()) {
                nameToId.put(d.name(), n.id());   // 重名时后者优先，精确引用建议用节点ID
            }
        }

        // 数据边：决定节点的输入数据
        Map<String, List<String>> dataIncoming = new HashMap<>();
        // 顺序边（数据边 + 隐式依赖）：只决定执行顺序
        Map<String, List<String>> orderOutgoing = new HashMap<>();
        Map<String, Integer> indegree = new HashMap<>();
        nodes.forEach(n -> indegree.put(n.id(), 0));

        for (GraphEdge e : edges) {
            dataIncoming.computeIfAbsent(e.target(), k -> new ArrayList<>()).add(e.source());
            orderOutgoing.computeIfAbsent(e.source(), k -> new ArrayList<>()).add(e.target());
            indegree.merge(e.target(), 1, Integer::sum);
        }

        // ★ 隐式依赖：config.dependsOn（节点ID或名称，逗号分隔），只排序不传数据
        for (GraphNode n : nodes) {
            for (String ref : parseDependsOn(n)) {
                String sourceId = nodeById.containsKey(ref) ? ref : nameToId.get(ref);
                if (sourceId == null || sourceId.equals(n.id())) continue;
                List<String> outs = orderOutgoing.computeIfAbsent(sourceId, k -> new ArrayList<>());
                if (!outs.contains(n.id())) {
                    outs.add(n.id());
                    indegree.merge(n.id(), 1, Integer::sum);
                }
            }
        }

        // Kahn 拓扑排序
        Deque<String> queue = new ArrayDeque<>();
        nodes.forEach(n -> { if (indegree.get(n.id()) == 0) queue.add(n.id()); });
        List<String> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            String id = queue.poll();
            order.add(id);
            for (String t : orderOutgoing.getOrDefault(id, List.of())) {
                if (indegree.merge(t, -1, Integer::sum) == 0) queue.add(t);
            }
        }
        if (order.size() != nodes.size()) {
            return new ExecutionResult(false, "流程中存在循环依赖（含 dependsOn 隐式依赖），请检查",
                    traces, Map.of(), 0);
        }

        DefaultFlowContext flowContext = new DefaultFlowContext(
                UUID.randomUUID().toString(), flowName, nameToId);

        Map<String, Object> outputs = new HashMap<>();
        Map<String, String> status = new HashMap<>();
        Map<String, Object> finalOutputs = new LinkedHashMap<>();
        boolean allSuccess = true;

        for (String id : order) {
            GraphNode node = nodeById.get(id);
            FlowNodeData data = node.data();
            String nodeName = data != null && data.name() != null ? data.name() : id;
            String defName = data != null ? data.defName() : null;
            List<String> sources = dataIncoming.getOrDefault(id, List.of());

            // 数据边上游未成功则跳过（隐式依赖不触发跳过，读取时会报明确错误）
            if (!sources.isEmpty() && sources.stream().anyMatch(s -> !"SUCCESS".equals(status.get(s)))) {
                status.put(id, "SKIPPED");
                traces.add(new NodeTrace(id, nodeName, defName, "SKIPPED", 0, null, "上游节点未成功执行"));
                allSuccess = false;
                continue;
            }

            NodeDefinition def = data == null ? null : registry.getDefinition(data.defId());
            if (def == null) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED", 0, null,
                        "未找到节点定义: " + (data == null ? "?" : data.defId())));
                continue;
            }

            List<Object> inputs = sources.stream().map(outputs::get).collect(Collectors.toList());
            long t0 = System.currentTimeMillis();
            try {
                Map<String, Object> config = data.config() == null ? Map.of() : data.config();
                Object result = registry.execute(def.id(),
                        new NodeContext(id, nodeName, config, inputs, flowContext));
                outputs.put(id, result);
                flowContext.putOutput(id, result);      // ★ 写入上下文
                status.put(id, "SUCCESS");
                traces.add(new NodeTrace(id, nodeName, defName, "SUCCESS",
                        System.currentTimeMillis() - t0, result, null));
                if (def.type() == NodeType.OUTPUT) {
                    finalOutputs.put(nodeName, result);
                }
            } catch (Exception ex) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED",
                        System.currentTimeMillis() - t0, null, message(ex)));
            }
        }

        return new ExecutionResult(allSuccess, allSuccess ? null : "部分节点执行失败",
                traces, finalOutputs, System.currentTimeMillis() - start);
    }

    private List<String> parseDependsOn(GraphNode n) {
        if (n.data() == null || n.data().config() == null) return List.of();
        Object v = n.data().config().get(DEPENDS_ON_KEY);
        if (v == null) return List.of();
        if (v instanceof List<?> list) {
            return list.stream().map(String::valueOf).map(String::trim)
                    .filter(s -> !s.isEmpty()).toList();
        }
        return Arrays.stream(String.valueOf(v).split("[,，]"))
                .map(String::trim).filter(s -> !s.isEmpty()).toList();
    }

    private String message(Throwable t) {
        return t.getMessage() == null ? t.getClass().getSimpleName() : t.getMessage();
    }
}
```

```java
private Object[] resolveArgs(Method method, NodeContext ctx) {
    Class<?>[] types = method.getParameterTypes();
    Object[] args = new Object[types.length];
    for (int i = 0; i < types.length; i++) {
        Class<?> t = types[i];
        if (NodeContext.class.isAssignableFrom(t)) args[i] = ctx;
        else if (FlowContext.class.isAssignableFrom(t)) args[i] = ctx.flowContext();   // ★ 新增
        else if (Map.class.isAssignableFrom(t)) args[i] = ctx.config() == null ? Map.of() : ctx.config();
        else if (List.class.isAssignableFrom(t)) args[i] = ctx.inputs() == null ? List.of() : ctx.inputs();
        else args[i] = (ctx.inputs() == null || ctx.inputs().isEmpty()) ? null : ctx.inputs().get(0);
    }
    return args;
}
```

### USER
这个dependson 干什么的？好像有点问题，输入数据应该不用排序吧？现在好像是对每个输入都做了计算节点操作。是不是可以计算节点 使用上面所有输入，然后计算出输出？现在满足吗？

### ASSISTANT
## 先给结论

1. **dependsOn 和数据排序无关**，它是可选的执行顺序约束，正常连线的话你这辈子都用不到它
2. **"计算节点一次性拿到所有上游输入、算出一个输出"——现在就是这个语义，已经满足**。每个节点在一次执行中只会被调用一次

下面详细解释。

## 一、dependsOn 到底是干什么的

它只解决**一个特定场景**：你想用 `FlowContext.getOutput("A")` 读 A 的数据，但**又不想画 A→C 的连线**。

问题在于：引擎是靠连线决定执行顺序的。没连线时，引擎不知道 C 依赖 A，万一 C 排在 A 前面执行，`getOutput` 就会拿不到数据。`dependsOn` 就是告诉引擎"C 执行前先把 A 执行了"——**只加顺序约束，不传数据**，相当于一条看不见的虚线。

所以：

- ✅ 你画了连线 → 顺序和数据都有了，**完全不需要 dependsOn**
- ✅ 输入节点没有上游，拓扑排序里天然最先执行，**更不需要任何排序配置**
- 只有"免连线读上下文"这种用法才配它。嫌它碍眼可以在前端对输入节点隐藏（下面有改法）

## 二、计算节点现在的真实语义：就是一次拿全部输入

引擎的执行逻辑是：

```
拓扑排序 → 按序每个节点【只执行一次】→ 执行前把所有直连上游的输出收集成 List 一次性传入
```

用示例流程里的「数值求和」(n4) 举例，它有两条入边（字段提取 n3 和 常量 n5），执行时是**一次调用**：

```
inputs = [ [199, 99, 1299],  10 ]     ← n3的输出 + n5的输出，一个列表
         ↓
   sum 方法被调用 1 次
         ↓
      1607
```

不是调用两次。方法里用 `List<Object> inputs` 接住全部上游输出，怎么合并（求和/拼接/取第一个……）是方法自己的逻辑。

## 三、你看到"像对每个输入都做了计算"，大概率是这三个原因

1. **示例里放了两个「字段提取」节点**（先提取 items、再提取 amount），它们是画布上两个独立节点、只是用了同一个节点定义，trace 里出现两行是正常的
2. **「字段提取」的输出是 `[199, 99, 1299]`**——这是这个节点**内部实现**在遍历列表逐个提取字段，看起来像执行了 3 次，实际引擎只调用了它 1 次。这是"列表逐元素处理"的节点逻辑，不是引擎行为
3. **最终输出 `[1607, 1607]`**——因为输出节点接了两条入边（n4 求和结果 + n7 上下文读取结果），输入列表有 2 个元素，这是为了演示两条取数路径

验证方法：运行后看底部执行结果，**每个节点有且只有一条 trace 记录**。

## 五、补充：如果你想要的是另一种语义

| 你想要的 | 现状 |
|---|---|
| 一个节点拿全部上游输入，算一次输出 | ✅ 已支持（`List<Object> inputs`） |
| 对每个上游输入分别算一次（map/逐条处理） | 属于节点内部逻辑，在方法里 for 循环即可 |
| 多个列表输入先拍平再算 | 方法里自己合并，或以后加个内置"合并输入"节点 |

也就是说"合并所有输入算一次"是引擎层语义，"怎么处理这些输入"是节点方法自己的事，现在这套划分是清晰的。改完跑一下示例，看 trace 里的输入个数就能确认行为了。

### USER
可以增加引用别的flow吗？比如一个大的流程，先是分成几个大步骤，然后每个步骤分其他小步骤。大步骤中的每个节点都是其他很多小步骤形成的流程。类似，画流程图，先画一级大骨架，然后再画二级，三级等。

### ASSISTANT
可以做，这就是工作流引擎里的**子流程（SubFlow / 流程引用）**能力，正好对应你说的"先画一级骨架，大步骤里每个节点其实是另一个完整小流程"的分层设计。

## 设计思路

新增一个内置节点「**引用流程**」，语义约定：

- **入参**：该节点的所有上游输出，打包成列表传给子流程，子流程内用`读取上下文`节点（目标填`入参`）或 `FlowContext.getOutput("入参")` 获取
- **出参**：子流程里所有**输出节点**的结果，作为本节点的输出（1个直接取值，多个返回 `{节点名: 结果}`）
- **递归执行**：引擎执行到该节点时递归执行被引用的流程，支持任意层级嵌套
- **防护**：循环引用检测（A引B、B引A）+ 最大嵌套深度 8 层
- 子流程内部的执行轨迹会带 `↳` 前缀并入父流程的执行结果面板，方便排查

## 3. 修改 `engine/FlowExecutionEngine.java`（整个替换）

```java
package com.example.flowengine.engine;

import com.example.flowengine.model.*;
import com.example.flowengine.registry.NodeRegistry;
import com.example.flowengine.repository.FlowRepository;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.stream.Collectors;

@Service
public class FlowExecutionEngine {

    public static final String DEPENDS_ON_KEY = "dependsOn";
    /** 子流程入参的虚拟节点ID */
    public static final String INPUTS_NODE_ID = "inputs";
    private static final int MAX_SUBFLOW_DEPTH = 8;

    private final NodeRegistry registry;
    private final FlowRepository repository;

    public FlowExecutionEngine(NodeRegistry registry, FlowRepository repository) {
        this.registry = registry;
        this.repository = repository;
    }

    public record NodeTrace(String nodeId, String nodeName, String defName, String status,
                            long durationMs, int inputCount, Object output, String error) {}

    public record ExecutionResult(boolean success, String error, List<NodeTrace> traces,
                                  Map<String, Object> outputs, long durationMs) {}

    public ExecutionResult execute(FlowGraph graph) {
        return execute(graph, null);
    }

    public ExecutionResult execute(FlowGraph graph, String flowName) {
        return doExecute(graph, flowName, new ArrayDeque<>(), null);
    }

    private ExecutionResult doExecute(FlowGraph graph, String flowName,
                                      Deque<String> flowStack, List<Object> seedInputs) {
        long start = System.currentTimeMillis();
        List<GraphNode> nodes = graph == null || graph.nodes() == null ? List.of() : graph.nodes();
        List<GraphEdge> edges = graph == null || graph.edges() == null ? List.of() : graph.edges();
        List<NodeTrace> traces = new ArrayList<>();

        if (nodes.isEmpty()) {
            return new ExecutionResult(false, "流程中没有节点", traces, Map.of(), 0);
        }

        Map<String, GraphNode> nodeById = nodes.stream()
                .collect(Collectors.toMap(GraphNode::id, n -> n));
        for (GraphEdge e : edges) {
            if (!nodeById.containsKey(e.source()) || !nodeById.containsKey(e.target())) {
                return new ExecutionResult(false, "连线引用了不存在的节点: " + e.id(), traces, Map.of(), 0);
            }
        }

        Map<String, String> nameToId = new HashMap<>();
        for (GraphNode n : nodes) {
            FlowNodeData d = n.data();
            if (d != null && d.name() != null && !d.name().isBlank()) {
                nameToId.put(d.name(), n.id());
            }
        }

        Map<String, List<String>> dataIncoming = new HashMap<>();
        Map<String, List<String>> orderOutgoing = new HashMap<>();
        Map<String, Integer> indegree = new HashMap<>();
        nodes.forEach(n -> indegree.put(n.id(), 0));

        for (GraphEdge e : edges) {
            dataIncoming.computeIfAbsent(e.target(), k -> new ArrayList<>()).add(e.source());
            orderOutgoing.computeIfAbsent(e.source(), k -> new ArrayList<>()).add(e.target());
            indegree.merge(e.target(), 1, Integer::sum);
        }

        for (GraphNode n : nodes) {
            for (String ref : parseDependsOn(n)) {
                String sourceId = nodeById.containsKey(ref) ? ref : nameToId.get(ref);
                if (sourceId == null || sourceId.equals(n.id())) continue;
                List<String> outs = orderOutgoing.computeIfAbsent(sourceId, k -> new ArrayList<>());
                if (!outs.contains(n.id())) {
                    outs.add(n.id());
                    indegree.merge(n.id(), 1, Integer::sum);
                }
            }
        }

        Deque<String> queue = new ArrayDeque<>();
        nodes.forEach(n -> { if (indegree.get(n.id()) == 0) queue.add(n.id()); });
        List<String> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            String id = queue.poll();
            order.add(id);
            for (String t : orderOutgoing.getOrDefault(id, List.of())) {
                if (indegree.merge(t, -1, Integer::sum) == 0) queue.add(t);
            }
        }
        if (order.size() != nodes.size()) {
            return new ExecutionResult(false, "流程中存在循环依赖（含 dependsOn 隐式依赖），请检查",
                    traces, Map.of(), 0);
        }

        DefaultFlowContext flowContext = new DefaultFlowContext(
                UUID.randomUUID().toString(), flowName, nameToId);

        // ★ 子流程入参：以虚拟节点"入参"注入上下文
        if (seedInputs != null && !seedInputs.isEmpty()) {
            flowContext.putOutput(INPUTS_NODE_ID, seedInputs);
            flowContext.registerAlias("入参", INPUTS_NODE_ID);
            flowContext.put("inputs", seedInputs);
        }

        Map<String, Object> outputs = new HashMap<>();
        Map<String, String> status = new HashMap<>();
        Map<String, Object> finalOutputs = new LinkedHashMap<>();
        boolean allSuccess = true;

        for (String id : order) {
            GraphNode node = nodeById.get(id);
            FlowNodeData data = node.data();
            String nodeName = data != null && data.name() != null ? data.name() : id;
            String defName = data != null ? data.defName() : null;
            List<String> sources = dataIncoming.getOrDefault(id, List.of());

            if (!sources.isEmpty() && sources.stream().anyMatch(s -> !"SUCCESS".equals(status.get(s)))) {
                status.put(id, "SKIPPED");
                traces.add(new NodeTrace(id, nodeName, defName, "SKIPPED", 0, sources.size(), null, "上游节点未成功执行"));
                allSuccess = false;
                continue;
            }

            NodeDefinition def = data == null ? null : registry.getDefinition(data.defId());
            if (def == null) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED", 0, 0, null,
                        "未找到节点定义: " + (data == null ? "?" : data.defId())));
                continue;
            }

            List<Object> inputs = sources.stream().map(outputs::get).collect(Collectors.toList());
            long t0 = System.currentTimeMillis();
            try {
                Map<String, Object> config = data.config() == null ? Map.of() : data.config();
                Object result;
                if (NodeRegistry.SUBFLOW_DEF_ID.equals(data.defId())) {
                    // ★ 子流程节点：递归执行被引用的流程
                    result = executeSubFlow(id, config, inputs, flowStack, traces);
                } else {
                    result = registry.execute(def.id(),
                            new NodeContext(id, nodeName, config, inputs, flowContext));
                }
                outputs.put(id, result);
                flowContext.putOutput(id, result);
                status.put(id, "SUCCESS");
                traces.add(new NodeTrace(id, nodeName, defName, "SUCCESS",
                        System.currentTimeMillis() - t0, inputs.size(), result, null));
                if (def.type() == NodeType.OUTPUT) {
                    finalOutputs.put(nodeName, result);
                }
            } catch (Exception ex) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED",
                        System.currentTimeMillis() - t0, inputs.size(), null, message(ex)));
            }
        }

        return new ExecutionResult(allSuccess, allSuccess ? null : "部分节点执行失败",
                traces, finalOutputs, System.currentTimeMillis() - start);
    }

    /** 递归执行子流程 */
    private Object executeSubFlow(String parentNodeId, Map<String, Object> config,
                                  List<Object> inputs, Deque<String> flowStack, List<NodeTrace> traces) {
        String refFlowId = config.get("flowId") == null ? null : String.valueOf(config.get("flowId")).trim();
        if (refFlowId == null || refFlowId.isEmpty()) {
            throw new IllegalArgumentException("未配置要引用的子流程（请选择子流程）");
        }
        if (flowStack.contains(refFlowId)) {
            List<String> chain = new ArrayList<>(flowStack);
            Collections.reverse(chain);
            throw new IllegalStateException("子流程循环引用: " + String.join(" → ", chain) + " → " + refFlowId);
        }
        if (flowStack.size() >= MAX_SUBFLOW_DEPTH) {
            throw new IllegalStateException("子流程嵌套层数超过上限: " + MAX_SUBFLOW_DEPTH);
        }
        Flow sub = repository.findById(refFlowId)
                .orElseThrow(() -> new IllegalArgumentException("子流程不存在或已删除: " + refFlowId));

        flowStack.push(refFlowId);
        try {
            ExecutionResult r = doExecute(sub.getGraph(), sub.getName(), flowStack, inputs);
            // 子流程内部轨迹并入父级（加前缀），便于排查
            for (NodeTrace t : r.traces()) {
                traces.add(new NodeTrace(parentNodeId + ":" + t.nodeId(), "↳ " + t.nodeName(), t.defName(),
                        t.status(), t.durationMs(), t.inputCount(), t.output(), t.error()));
            }
            if (!r.success()) {
                throw new IllegalStateException("子流程[" + sub.getName() + "]执行失败: "
                        + (r.error() == null ? "" : r.error()));
            }
            Map<String, Object> outs = r.outputs();
            if (outs.isEmpty()) return null;
            if (outs.size() == 1) return outs.values().iterator().next();
            return outs;   // 多个输出节点时返回 {节点名: 结果}
        } finally {
            flowStack.pop();
        }
    }

    private List<String> parseDependsOn(GraphNode n) {
        if (n.data() == null || n.data().config() == null) return List.of();
        Object v = n.data().config().get(DEPENDS_ON_KEY);
        if (v == null) return List.of();
        if (v instanceof List<?> list) {
            return list.stream().map(String::valueOf).map(String::trim)
                    .filter(s -> !s.isEmpty()).toList();
        }
        return Arrays.stream(String.valueOf(v).split("[,，]"))
                .map(String::trim).filter(s -> !s.isEmpty()).toList();
    }

    private String message(Throwable t) {
        return t.getMessage() == null ? t.getClass().getSimpleName() : t.getMessage();
    }
}
```

## 用起来是什么样

1. 左侧节点库多出「引用流程」节点，拖到画布，右侧面板用**下拉框**选择要引用的流程

- 循环引用（A引B、B引A）和超过 8 层嵌套会被引擎直接拦截并报错

### USER
按理说 子流程不会拿取主流程前面所有节点数据吧，它应该有范围限制，只获取它需要的数据就行。

### ASSISTANT
你的直觉是对的，这里先把现状说清楚，再补一个真正缺的东西。

## 一、先澄清：现在其实已经有范围限制

子流程**不是**拿到主流程前面所有节点的数据，现在有两条隔离规则：

1. **只拿直连上游**：子流程节点收到的 `入参`，只是**直接连线到"引用流程"节点**的那些上游的输出。没连线的节点，数据根本传不进来——画布上的连线就是范围边界，想让子流程拿什么，就把什么连给它
2. **上下文完全隔离**：子流程执行时会新建一个独立的 `FlowContext`，它在里面 `getOutput("主流程某节点")` 是拿不到的，只能看到显式传进来的入参

所以"只获取它需要的数据"在机制上已经成立：**连了才给，没连看不到**。

## 二、真正的问题：多个输入时是一个"无名列表"

比如你把「总金额」和「用户信息」两个节点都连给子流程节点，子流程拿到的是 `入参 = [值1, 值2]`——**按位置区分，不知道哪个是哪个**，连法一变顺序就乱。这才是该修的。

方案：**给连线命名**。双击连线输入名称，子流程内直接按名称取数：`getOutput("总金额")`。

```java
    flowContext.registerAlias("入参", INPUTS_NODE_ID);
    flowContext.put("inputs", seedInputs);
}
// ★ 命名入参：每条有名称的入边，注册为子流程内可按名读取的虚拟节点
if (seedNamedInputs != null && !seedNamedInputs.isEmpty()) {
    for (Map.Entry<String, Object> en : seedNamedInputs.entrySet()) {
        if ("入参".equals(en.getKey()) || "inputs".equals(en.getKey())) continue;
        String virtualId = "input:" + en.getKey();
        flowContext.putOutput(virtualId, en.getValue());
        flowContext.registerAlias(en.getKey(), virtualId);
        flowContext.put(en.getKey(), en.getValue());
    }
}
```

## 改完后的用法

| 场景 | 做法 |
|---|---|
| 子流程只要一个输入 | 连一条线过去，子流程里读 `入参`（或给线命名后按名称读） |
| 子流程要多个不同输入 | 各连一条线，**双击每条线命名**，子流程里 `读取上下文(目标=线名)` 或代码里 `ctx.getOutput("总金额")` |
| 不想让子流程拿到某节点数据 | 不连线即可，它完全看不到 |

一句话总结这层的边界模型：

> **连线 = 数据入口，线名 = 参数名，子流程上下文 = 独立沙箱。**
> 主流程其他节点的数据，没连线就进不来；子流程也看不到主流程上下文。

这样你画一级骨架时，每个"引用流程"节点就像函数调用：入边是实参，线名是形参名，子流程是函数体——作用域天然干净。以后如果要更严格，还可以再做"子流程声明入参列表（形参定义），引用时校验实参是否齐全"，需要的话下一步加。

### USER
假如后面加入类似  循环 判断 这种节点，你觉得是加入这种节点好？还是在每个节点增加一个boolean值 根据值来确定是否执行好？

### ASSISTANT
结论先说：**用专门的控制节点（条件、循环），不要用"每个节点加 boolean"**。但 boolean 思路有个轻量变体可以作为补充。下面说理由和落地设计。

## 一、为什么"每节点一个 boolean"撑不起来

| 能力 | 专用控制节点 | 每节点 boolean |
|---|---|---|
| 某节点临时禁用 | ✅ | ✅ |
| 按运行时条件决定走不走 | ✅ | ⚠️ 得升级成表达式才行 |
| **分支：二选一/多选一** | ✅ | ❌ 做不到 |
| **循环：执行 N 次/遍历列表** | ✅ | ❌ 做不到 |
| 逻辑可读性 | 决策点在画布上一目了然 | 条件散落在每个节点里，排查靠猜 |

关键缺陷有两个：

1. **分支做不了**。boolean 只能决定"这个节点自己跑不跑"，不能决定"走 A 路径还是 B 路径"。想实现 if-else，你得把同一个条件复制到两条路径的每个节点上——改一处漏一处，而且画布上完全看不出这里有个判断
2. **循环做不了**。现在的引擎是拓扑排序、**每个节点只执行一次**。boolean 再怎么写也只是"跑/不跑"，表达不了"跑 10 次""对列表每个元素跑一遍"——这需要重复执行语义，是另一个维度的东西

所以 boolean 顶多是个"静态开关"，控制流需要一等公民。

## 二、控制节点怎么设计，才能贴合你现在的架构

好消息是：你已经有了**子流程**机制，循环和判断都能很自然地长出来。

### 1. 条件节点（分支）——需要给边加"输出口"

```
        ┌─(true)─→ 节点A
条件路由 ┤
        └─(false)→ 节点B
```

- 节点方法返回**激活哪个输出口**，比如返回 `"true"` / `"false"`
- 条件表达式用 **SpEL**（Spring Boot 自带，不用引新依赖）：`#input[0] > 100`
- 需要的改造：
  - `GraphEdge` 加 `sourceHandle`（这条线是从哪个口出来的）——和你上次加 `label` 一个套路
  - `NodeDefinition` 支持声明多个输出端口，前端节点渲染多个右侧 Handle
  - 引擎：条件节点执行后，只"点亮"选中端口出去的边；没被点亮的下游整条分支标记 `SKIPPED（分支未命中）`。注意汇合点规则：**多个上游只要有一条激活边就执行**，输入列表只收激活边的值

```java
@FlowNode(name = "条件路由", type = NodeType.COMPUTE)
public Object route(List<Object> inputs, Map<String, Object> config) {
    String expr = (String) config.get("expression");   // 如 "#input[0] > 100"
    Boolean hit = spelEval(expr, inputs, config);
    return Boolean.TRUE.equals(hit) ? "true" : "false";  // 返回值 = 激活的输出口
}
```

### 2. 循环节点——直接复用了流程机制，外层图保持 DAG

这是重点建议：**不要把循环画成图里的回边**（尾节点连回头部那种）。回边会打破拓扑排序、让执行状态变得极难推理，还容易死循环。成熟做法是**循环体封装成子流程，循环节点负责重复调用**：

```
循环节点配置：
  - 循环体：引用某个子流程（复用"引用流程"那套）
  - 迭代输入：入参里哪个列表（如 "入参"）
引擎行为：
  for (int i = 0; i < list.size(); i++)
      执行一次子流程，入参 = [当前元素, 索引i]
  收集每轮输出 → 合并成列表作为循环节点的输出
```

这样你现有的 `executeSubFlow`、入参传递、轨迹前缀（`↳`）几乎原样复用，只需要在外面套一层 for + 最大迭代次数保护（比如 1000 次上限，防死循环）。后续要 `while` 循环也一样：每轮先用 SpEL 判条件，不满足就停。

### 3. boolean 思路的正确用法：节点级"执行条件"（补充，不是主角）

如果确实有"这个节点满足某条件才执行"的小需求，给节点加一个可选配置 `executeIf`（SpEL 表达式，空=总是执行），引擎在执行前求值，不满足就 `SKIPPED`。这是分支能力的下沉，成本几行代码，但它**只处理单节点跳过，不处理路径选择**——分工要清楚。

## 三、建议的演进顺序

1. **先做条件路由**：价值最高，改造面也清晰（边的 `sourceHandle` + 多输出端口 + 引擎"点亮/跳过"机制）。这套机制做完，后面所有分支类需求都通了
2. **再做 foreach 循环**：建立在子流程之上，主要是循环节点本身 + 迭代上限保护
3. **最后按需加 `executeIf`** 节点级条件、`while` 循环
4. 每步都记得给对应前端配套：条件节点的多 Handle 渲染、连线上显示端口名、循环轨迹的层级展示（第几轮）

一句话总结：**控制流用节点表达（看得见、可复用、可嵌套），布尔开关只做单节点的静态/动态启停**。你的架构里子流程机制已经把循环最难的部分铺好路了，先做条件节点吧，需要的话我可以直接把条件路由这套（含多输出端口和引擎激活机制）实现出来。
