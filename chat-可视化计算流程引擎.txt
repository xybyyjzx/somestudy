### USER
我有一套很复杂的计算逻辑，需要调用很多个方法，我想可视化一下。想着弄一个计算引擎平台。可以展示节点，拖动节点连线，执行flow，新建flow，保存flow，节点可以修改名称，描述等。然后节点主要有三个类型，输入 输出 计算。输入节点可以支持json，excel，htttp db等 现在最小版本只需要json。输出节点和输入节点类似。计算节点可以有多个输入节点，也可以有多个输出节点。最好弄一个注解，可以把现有的方法直接变成节点。左侧展示节点，中间展示画布，点击画布上节点，可以修改节点一些配置，比如参数，名称，描述等。我用的springboot3 vue3 typescript。这个计算平台可以可视化现有的一套flow计算逻辑，也可以根据节点新建flow。先帮我实现一个最小版本。

### ASSISTANT
下面给你一套**可直接运行的最小版本**：Spring Boot 3 后端（注解扫描 → 节点注册表 → 拓扑执行引擎）+ Vue3 + TS + Vue Flow 前端（左侧节点库 / 中间画布 / 右侧属性面板）。

## 整体设计

- **`@FlowNode` 注解**打在任意 Spring Bean 的方法上，启动时自动扫描注册成节点（这是你要的"把现有方法直接变成节点"）。
- 方法签名约定：`(Map data)` 或 `(Map data, Map config)`。输入节点 data=节点配置；计算节点 data=各输入端口的数据；多输出节点返回 `Map<端口名, 数据>`。
- 执行引擎：Kahn 拓扑排序 → 按序反射调用 → 每个节点返回状态/耗时/输出预览，前端画布上直接标绿/标红。
- 存储：MVP 用内存 Map，之后换 JPA 只改一个类。

```java
package com.example.flowengine.annotation;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

/**
 * 打在任意 Spring Bean 的方法上，启动时自动注册为流程节点。
 * 方法签名约定：
 *   Object xxx(Map<String,Object> data)                    —— 单参
 *   Object xxx(Map<String,Object> data, Map<String,Object> config) —— 双参
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface FlowNode {
    /** 唯一 key，缺省用 类名.方法名 */
    String key() default "";
    String name();
    String description() default "";
    NodeType type() default NodeType.COMPUTE;
    /** 输入端口，计算/输出节点缺省为 ["in"] */
    String[] inputs() default {};
    /** 输出端口，计算/输入节点缺省为 ["out"]；多输出时方法需返回 Map<端口名,数据> */
    String[] outputs() default {};
    NodeParam[] params() default {};
}
```

```java
package com.example.flowengine.registry;

import com.example.flowengine.annotation.NodeType;

import java.lang.reflect.Method;
import java.util.List;
import java.util.Map;

public class NodeDefinition {

    private final String key;
    private final String name;
    private final String description;
    private final NodeType type;
    private final List<String> inputs;
    private final List<String> outputs;
    private final List<ParamDefinition> params;
    private final Object bean;
    private final Method method;

    public NodeDefinition(String key, String name, String description, NodeType type,
                          List<String> inputs, List<String> outputs, List<ParamDefinition> params,
                          Object bean, Method method) {
        this.key = key; this.name = name; this.description = description; this.type = type;
        this.inputs = inputs; this.outputs = outputs; this.params = params;
        this.bean = bean; this.method = method;
    }

    /** 反射执行节点方法（支持单参 / 双参两种签名） */
    public Object invoke(Object data, Map<String, Object> config) throws Exception {
        if (method.getParameterCount() >= 2) {
            return method.invoke(bean, data, config);
        }
        return method.invoke(bean, data);
    }

    public String getKey() { return key; }
    public String getName() { return name; }
    public String getDescription() { return description; }
    public NodeType getType() { return type; }
    public List<String> getInputs() { return inputs; }
    public List<String> getOutputs() { return outputs; }
    public List<ParamDefinition> getParams() { return params; }
}
```

```java
package com.example.flowengine.registry;

import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.annotation.NodeType;
import jakarta.annotation.PostConstruct;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.aop.framework.AopProxyUtils;
import org.springframework.aop.support.AopUtils;
import org.springframework.context.ApplicationContext;
import org.springframework.core.annotation.AnnotatedElementUtils;
import org.springframework.stereotype.Component;
import org.springframework.util.ReflectionUtils;

import java.util.*;

/** 启动时扫描所有 Bean，收集 @FlowNode 方法，形成节点库 */
@Component
public class NodeRegistry {

    private static final Logger log = LoggerFactory.getLogger(NodeRegistry.class);

    private final ApplicationContext context;
    private final Map<String, NodeDefinition> definitions = new LinkedHashMap<>();

    public NodeRegistry(ApplicationContext context) {
        this.context = context;
    }

    @PostConstruct
    public void scan() {
        for (String beanName : context.getBeanDefinitionNames()) {
            Object bean;
            try {
                bean = context.getBean(beanName);
            } catch (Exception e) {
                continue;
            }
            Class<?> clazz = AopUtils.isAopProxy(bean) ? AopProxyUtils.ultimateTargetClass(bean) : bean.getClass();
            if (clazz.getName().startsWith("org.springframework")) continue;

            ReflectionUtils.doWithMethods(clazz, method -> {
                FlowNode ann = AnnotatedElementUtils.findMergedAnnotation(method, FlowNode.class);
                if (ann == null || method.isSynthetic() || method.isBridge()) return;
                ReflectionUtils.makeAccessible(method);

                String key = ann.key().isBlank() ? clazz.getSimpleName() + "." + method.getName() : ann.key();
                NodeType type = ann.type();
                List<String> inputs = ann.inputs().length > 0 ? List.of(ann.inputs())
                        : (type == NodeType.INPUT ? List.of() : List.of("in"));
                List<String> outputs = ann.outputs().length > 0 ? List.of(ann.outputs())
                        : (type == NodeType.OUTPUT ? List.of() : List.of("out"));
                List<ParamDefinition> params = Arrays.stream(ann.params())
                        .map(p -> new ParamDefinition(p.name(), p.description(), p.defaultValue()))
                        .toList();

                definitions.put(key, new NodeDefinition(key, ann.name(), ann.description(),
                        type, inputs, outputs, params, bean, method));
                log.info("注册流程节点: {} ({})", key, ann.name());
            });
        }
        log.info("共注册流程节点 {} 个", definitions.size());
    }

    public Collection<NodeDefinition> list() { return definitions.values(); }
    public NodeDefinition get(String key) { return definitions.get(key); }
}
```

### 执行引擎：`engine/FlowExecutor.java`

```java
package com.example.flowengine.engine;

import com.example.flowengine.core.FlowDefinition;
import com.example.flowengine.core.FlowEdge;
import com.example.flowengine.core.FlowNodeInstance;
import com.example.flowengine.dto.ExecutionResultDto;
import com.example.flowengine.dto.NodeResultDto;
import com.example.flowengine.registry.NodeDefinition;
import com.example.flowengine.registry.NodeRegistry;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.stereotype.Component;

import java.lang.reflect.InvocationTargetException;
import java.util.*;
import java.util.stream.Collectors;

/** 拓扑排序后按序执行节点；节点间以「端口名 -> 数据」传递 */
@Component
public class FlowExecutor {

    private static final int PREVIEW_LIMIT = 2000;

    private final NodeRegistry registry;
    private final ObjectMapper mapper = new ObjectMapper();

    public FlowExecutor(NodeRegistry registry) {
        this.registry = registry;
    }

    public ExecutionResultDto execute(FlowDefinition flow) {
        long start = System.currentTimeMillis();
        Map<String, FlowNodeInstance> nodeMap = flow.getNodes().stream()
                .collect(Collectors.toMap(FlowNodeInstance::getId, n -> n));
        Map<String, List<FlowEdge>> incoming = flow.getEdges().stream()
                .collect(Collectors.groupingBy(FlowEdge::getTarget));
        Map<String, List<FlowEdge>> outgoing = flow.getEdges().stream()
                .collect(Collectors.groupingBy(FlowEdge::getSource));

        List<String> order = topoSort(flow, outgoing);
        if (order.size() != flow.getNodes().size()) {
            return new ExecutionResultDto("FAILED", System.currentTimeMillis() - start,
                    Map.of(), "流程中存在环，请检查节点连线");
        }

        Map<String, Object> outputs = new HashMap<>();   // nodeId -> 节点输出
        Map<String, NodeResultDto> results = new LinkedHashMap<>();
        boolean failed = false;

        for (String nodeId : order) {
            if (failed) {
                results.put(nodeId, new NodeResultDto("SKIPPED", 0, null, null));
                continue;
            }
            FlowNodeInstance node = nodeMap.get(nodeId);
            long t0 = System.currentTimeMillis();
            NodeDefinition def = registry.get(node.getNodeKey());
            if (def == null) {
                results.put(nodeId, new NodeResultDto("ERROR", 0, null, "未找到节点定义：" + node.getNodeKey()));
                failed = true;
                continue;
            }
            try {
                Map<String, Object> config = node.getConfig() == null ? Map.of() : node.getConfig();
                Object dataArg = switch (def.getType()) {
                    case INPUT -> config;
                    case COMPUTE -> collectInputs(node, incoming, outputs);
                    case OUTPUT -> {
                        Map<String, Object> inputs = collectInputs(node, incoming, outputs);
                        inputs.put("value", inputs.isEmpty() ? null : inputs.values().iterator().next());
                        yield inputs;
                    }
                };
                Object result = def.invoke(dataArg, config);
                outputs.put(nodeId, result);
                results.put(nodeId, new NodeResultDto("SUCCESS", System.currentTimeMillis() - t0, preview(result), null));
            } catch (Exception ex) {
                Throwable cause = ex instanceof InvocationTargetException && ex.getCause() != null ? ex.getCause() : ex;
                results.put(nodeId, new NodeResultDto("ERROR", System.currentTimeMillis() - t0, null,
                        cause.getClass().getSimpleName() + ": " + cause.getMessage()));
                failed = true;
            }
        }
        return new ExecutionResultDto(failed ? "FAILED" : "SUCCESS", System.currentTimeMillis() - start, results, null);
    }

    private List<String> topoSort(FlowDefinition flow, Map<String, List<FlowEdge>> outgoing) {
        Map<String, Integer> indegree = new LinkedHashMap<>();
        flow.getNodes().forEach(n -> indegree.put(n.getId(), 0));
        for (FlowEdge e : flow.getEdges()) {
            if (indegree.containsKey(e.getSource()) && indegree.containsKey(e.getTarget())) {
                indegree.merge(e.getTarget(), 1, Integer::sum);
            }
        }
        Deque<String> queue = new ArrayDeque<>();
        indegree.forEach((id, d) -> { if (d == 0) queue.add(id); });
        List<String> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            String id = queue.poll();
            order.add(id);
            for (FlowEdge e : outgoing.getOrDefault(id, List.of())) {
                if (indegree.merge(e.getTarget(), -1, Integer::sum) == 0) queue.add(e.getTarget());
            }
        }
        return order;
    }

    /** 收集一个节点所有输入端口的数据：{输入端口名: 上游对应输出} */
    private Map<String, Object> collectInputs(FlowNodeInstance node, Map<String, List<FlowEdge>> incoming,
                                              Map<String, Object> outputs) {
        Map<String, Object> map = new LinkedHashMap<>();
        for (FlowEdge e : incoming.getOrDefault(node.getId(), List.of())) {
            Object upstream = outputs.get(e.getSource());
            String handle = e.getSourceHandle();
            Object value = (upstream instanceof Map<?, ?> m && handle != null && m.containsKey(handle))
                    ? m.get(handle) : upstream;
            String targetPort = (e.getTargetHandle() == null || e.getTargetHandle().isBlank()) ? "in" : e.getTargetHandle();
            map.put(targetPort, value);
        }
        return map;
    }

    private String preview(Object result) {
        try {
            String json = mapper.writeValueAsString(result);
            return json.length() > PREVIEW_LIMIT ? json.substring(0, PREVIEW_LIMIT) + "...(截断)" : json;
        } catch (Exception e) {
            return String.valueOf(result);
        }
    }
}
```

### 内置节点：`nodes/BuiltinNodes.java`

这就是"注解变节点"的示范。以后你接入 Excel/HTTP/DB 输入、或把你现有的业务方法变成节点，照抄这个套路即可。

```java
package com.example.flowengine.nodes;

import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.annotation.NodeParam;
import com.example.flowengine.annotation.NodeType;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.stream.Collectors;

@Component
public class BuiltinNodes {

    private final ObjectMapper mapper = new ObjectMapper();

    // ---------------- 输入节点（MVP 只做 JSON，后续可加 excel/http/db） ----------------

    @FlowNode(key = "input.json", name = "JSON 输入", type = NodeType.INPUT, outputs = "out",
            description = "从 JSON 字符串读取数据（支持数组或对象）",
            params = @NodeParam(name = "jsonText", description = "JSON 字符串", defaultValue = "[]"))
    public Object jsonInput(Map<String, Object> config) throws Exception {
        String json = str(config.get("jsonText"));
        if (json.isBlank()) json = "[]";
        return mapper.readValue(json, Object.class);
    }

    // ---------------- 输出节点 ----------------

    @FlowNode(key = "output.json", name = "JSON 输出", type = NodeType.OUTPUT, inputs = "in",
            description = "将数据序列化为 JSON 输出（可在此扩展写文件/推送）")
    public Object jsonOutput(Map<String, Object> context) throws Exception {
        Object value = context.get("value");
        String json = mapper.writerWithDefaultPrettyPrinter().writeValueAsString(value);
        return Map.of("chars", json.length(), "preview", truncate(json, 800));
    }

    // ---------------- 计算节点 ----------------

    @FlowNode(key = "compute.filter", name = "过滤", type = NodeType.COMPUTE, inputs = "in", outputs = "out",
            description = "按条件过滤列表数据",
            params = {
                    @NodeParam(name = "field", description = "字段名"),
                    @NodeParam(name = "operator", description = "eq / ne / gt / lt / contains", defaultValue = "eq"),
                    @NodeParam(name = "value", description = "比较值")
            })
    public Object filter(Map<String, Object> in, Map<String, Object> config) {
        String field = str(config.get("field"));
        String op = strOr(config.get("operator"), "eq");
        String expected = str(config.get("value"));
        return rows(in.get("in")).stream()
                .filter(row -> match(row.get(field), op, expected))
                .collect(Collectors.toList());
    }

    @FlowNode(key = "compute.select", name = "字段筛选", type = NodeType.COMPUTE, inputs = "in", outputs = "out",
            description = "仅保留指定字段",
            params = @NodeParam(name = "fields", description = "保留字段，英文逗号分隔"))
    public Object select(Map<String, Object> in, Map<String, Object> config) {
        List<String> fields = Arrays.stream(str(config.get("fields")).split("[,，]"))
                .map(String::trim).filter(s -> !s.isEmpty()).toList();
        return rows(in.get("in")).stream().map(row -> {
            Map<String, Object> kept = new LinkedHashMap<>();
            fields.forEach(f -> kept.put(f, row.get(f)));
            return kept;
        }).collect(Collectors.toList());
    }

    @FlowNode(key = "compute.split", name = "条件分流", type = NodeType.COMPUTE, inputs = "in",
            outputs = {"passed", "rejected"},
            description = "按 字段==值 拆成 passed / rejected 两路（多输出示例）",
            params = {
                    @NodeParam(name = "field", description = "字段名"),
                    @NodeParam(name = "value", description = "等于该值走 passed")
            })
    public Object split(Map<String, Object> in, Map<String, Object> config) {
        String field = str(config.get("field"));
        String expected = str(config.get("value"));
        List<Map<String, Object>> passed = new ArrayList<>();
        List<Map<String, Object>> rejected = new ArrayList<>();
        for (Map<String, Object> row : rows(in.get("in"))) {
            (String.valueOf(row.get(field)).equals(expected) ? passed : rejected).add(row);
        }
        return Map.of("passed", passed, "rejected", rejected);
    }

    @FlowNode(key = "compute.merge", name = "合并", type = NodeType.COMPUTE,
            inputs = {"left", "right"}, outputs = "out",
            description = "将两个输入的数据列表合并为一个（多输入示例）")
    public Object merge(Map<String, Object> in) {
        List<Object> merged = new ArrayList<>(asList(in.get("left")));
        merged.addAll(asList(in.get("right")));
        return merged;
    }

    @FlowNode(key = "compute.aggregate", name = "聚合统计", type = NodeType.COMPUTE, inputs = "in", outputs = "out",
            description = "对数值字段做 count / sum / avg / min / max",
            params = {
                    @NodeParam(name = "field", description = "数值字段"),
                    @NodeParam(name = "op", description = "count / sum / avg / min / max", defaultValue = "sum")
            })
    public Object aggregate(Map<String, Object> in, Map<String, Object> config) {
        List<Map<String, Object>> list = rows(in.get("in"));
        String field = str(config.get("field"));
        String op = strOr(config.get("op"), "sum");
        List<Double> values = list.stream().map(row -> toDouble(row.get(field))).filter(Objects::nonNull).toList();
        double result = switch (op) {
            case "count" -> list.size();
            case "avg" -> values.stream().mapToDouble(Double::doubleValue).average().orElse(0);
            case "min" -> values.stream().mapToDouble(Double::doubleValue).min().orElse(0);
            case "max" -> values.stream().mapToDouble(Double::doubleValue).max().orElse(0);
            default -> values.stream().mapToDouble(Double::doubleValue).sum();
        };
        return Map.of("op", op, "field", field, "rowCount", list.size(), "value", result);
    }

    // ---------------- 工具 ----------------

    private static boolean match(Object actual, String op, String expected) {
        String a = String.valueOf(actual);
        return switch (op) {
            case "ne" -> !a.equals(expected);
            case "gt" -> cmp(a, expected) > 0;
            case "lt" -> cmp(a, expected) < 0;
            case "contains" -> a.contains(expected);
            default -> a.equals(expected);
        };
    }

    private static int cmp(String a, String b) {
        Double da = toDouble(a), db = toDouble(b);
        if (da != null && db != null) return Double.compare(da, db);
        return a.compareTo(b);
    }

    private static Double toDouble(Object o) {
        if (o == null) return null;
        if (o instanceof Number n) return n.doubleValue();
        try { return Double.parseDouble(String.valueOf(o)); } catch (NumberFormatException e) { return null; }
    }

    @SuppressWarnings("unchecked")
    private static List<Map<String, Object>> rows(Object value) {
        return asList(value).stream()
                .filter(o -> o instanceof Map)
                .map(o -> (Map<String, Object>) o)
                .collect(Collectors.toList());
    }

    private static List<Object> asList(Object value) {
        if (value == null) return List.of();
        if (value instanceof Collection<?> c) return new ArrayList<>(c);
        return new ArrayList<>(List.of(value));
    }

    private static String str(Object o) { return o == null ? "" : String.valueOf(o); }
    private static String strOr(Object o, String def) { String s = str(o); return s.isBlank() ? def : s; }
    private static String truncate(String s, int max) { return s.length() <= max ? s : s.substring(0, max) + "...(截断)"; }
}
```

```java
package com.example.flowengine.storage;

import com.example.flowengine.core.FlowDefinition;
import org.springframework.stereotype.Repository;

import java.time.Instant;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

/** MVP 内存存储，后续可无缝替换为 JPA/数据库实现 */
@Repository
public class InMemoryFlowRepository {

    private final Map<String, FlowDefinition> store = new ConcurrentHashMap<>();

    public FlowDefinition save(FlowDefinition flow) {
        if (flow.getId() == null || flow.getId().isBlank()) {
            flow.setId(UUID.randomUUID().toString());
        }
        flow.setUpdatedAt(Instant.now());
        store.put(flow.getId(), flow);
        return flow;
    }

    public List<FlowDefinition> findAll() {
        return store.values().stream()
                .sorted(Comparator.comparing(FlowDefinition::getUpdatedAt,
                        Comparator.nullsLast(Comparator.reverseOrder())))
                .toList();
    }

    public Optional<FlowDefinition> findById(String id) {
        return Optional.ofNullable(store.get(id));
    }

    public void deleteById(String id) {
        store.remove(id);
    }
}
```

```java
        this.repository = repository;
        this.executor = executor;
    }

    @GetMapping
    public List<FlowDefinition> list() {
        return repository.findAll();
    }

    @GetMapping("/{id}")
    public ResponseEntity<FlowDefinition> get(@PathVariable String id) {
        return repository.findById(id).map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());
    }

    @PostMapping
    public FlowDefinition create(@RequestBody FlowDefinition flow) {
        flow.setId(null);
        return repository.save(flow);
    }

    @PutMapping("/{id}")
    public ResponseEntity<FlowDefinition> update(@PathVariable String id, @RequestBody FlowDefinition flow) {
        if (repository.findById(id).isEmpty()) return ResponseEntity.notFound().build();
        flow.setId(id);
        return ResponseEntity.ok(repository.save(flow));
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable String id) {
        repository.deleteById(id);
        return ResponseEntity.noContent().build();
    }

    /** 执行已保存的流程 */
    @PostMapping("/{id}/execute")
    public ResponseEntity<ExecutionResultDto> execute(@PathVariable String id) {
        return repository.findById(id)
                .map(flow -> ResponseEntity.ok(executor.execute(flow)))
                .orElse(ResponseEntity.notFound().build());
    }

    /** 直接执行画布当前内容（未保存也能跑） */
    @PostMapping("/execute")
```

```java
    @Bean
    CommandLineRunner seedDemoFlow(InMemoryFlowRepository repository) {

                    [
                      { "orderId": "A001", "status": "PAID", "amount": 120.5 },
                      { "orderId": "A002", "status": "UNPAID", "amount": 60 },
                      { "orderId": "A003", "status": "PAID", "amount": 300 },

                    ]""";

            FlowDefinition flow = new FlowDefinition();

            flow.setDescription("JSON 输入 → 过滤已支付 → 金额求和 → JSON 输出");
            flow.setNodes(List.of(

                    node("n2", "compute.filter", "过滤已支付", 330, 160,
                            Map.of("field", "status", "operator", "eq", "value", "PAID")),
                    node("n3", "compute.aggregate", "金额求和", 620, 160,
                            Map.of("field", "amount", "op", "sum")),
                    node("n4", "output.json", "结果输出", 910, 160, Map.of())
            ));
            flow.setEdges(List.of(
                    edge("n1", "out", "n2", "in"),
                    edge("n2", "out", "n3", "in"),
                    edge("n3", "out", "n4", "in")
            ));
            repository.save(flow);
        };
    }

    private static FlowNodeInstance node(String id, String key, String name,
                                         double x, double y, Map<String, Object> config) {
        FlowNodeInstance n = new FlowNodeInstance();
        n.setId(id); n.setNodeKey(key); n.setName(name); n.setX(x); n.setY(y);
        n.setConfig(new HashMap<>(config));
        return n;
    }

    private static FlowEdge edge(String source, String sourceHandle, String target, String targetHandle) {
        FlowEdge e = new FlowEdge();
        e.setId(source + "->" + target);
        e.setSource(source); e.setSourceHandle(sourceHandle);
        e.setTarget(target); e.setTargetHandle(targetHandle);
        return e;
    }
```

```vue
<script setup lang="ts">
import { markRaw, ref } from 'vue'
import { VueFlow, useVueFlow, type Connection, type Edge, type Node } from '@vue-flow/core'
import { Background } from '@vue-flow/background'
import { Controls } from '@vue-flow/controls'
import { MiniMap } from '@vue-flow/minimap'
import FlowNodeView from './nodes/FlowNodeView.vue'
import type { ExecutionResult, FlowDefinition, FlowNodeData, NodeDefinition } from '../types'

const props = defineProps<{ definitions: Map<string, NodeDefinition> }>()
const emit = defineEmits<{ (e: 'select', node: Node | null): void }>()

const nodeTypes = {
  input: markRaw(FlowNodeView),
  compute: markRaw(FlowNodeView),
  output: markRaw(FlowNodeView),
}

const nodes = ref<Node[]>([])
const edges = ref<Edge[]>([])

const { screenToFlowPosition, onConnect, onNodeClick, onPaneClick } = useVueFlow('main-flow')

let seq = 0

onConnect((conn: Connection) => {
  if (conn.source === conn.target) return
  edges.value.push({
    id: `e-${Date.now()}-${seq++}`,
    source: conn.source,
    target: conn.target,
    sourceHandle: conn.sourceHandle ?? undefined,
    targetHandle: conn.targetHandle ?? undefined,
  })
})

onNodeClick(({ node }) => emit('select', node))
onPaneClick(() => emit('select', null))

function addNodeByKey(key: string, position: { x: number; y: number }) {
  const def = props.definitions.get(key)
  if (!def) return
  const config: Record<string, unknown> = {}
  def.params.forEach((p) => {
    if (p.defaultValue) config[p.name] = p.defaultValue
  })
  nodes.value.push({
    id: `node-${Date.now()}-${seq++}`,
    type: def.type.toLowerCase(),
    position,
    data: { nodeKey: def.key, name: def.name, description: def.description, config, def } satisfies FlowNodeData,
  })
}

function onDrop(event: DragEvent) {
  const key = event.dataTransfer?.getData('application/flow-node')
  if (!key) return
  addNodeByKey(key, screenToFlowPosition({ x: event.clientX, y: event.clientY }))
}

function getFlowData(name: string, id?: string | null, description?: string): FlowDefinition {
  return {
    id: id ?? undefined,
    name,
    description,
    nodes: nodes.value.map((n) => {
      const d = n.data as FlowNodeData
      return {
        id: n.id, nodeKey: d.nodeKey, name: d.name, description: d.description,
        x: n.position.x, y: n.position.y, config: d.config,
      }
    }),
    edges: edges.value.map((e) => ({
      id: e.id, source: e.source, target: e.target,
      sourceHandle: e.sourceHandle ?? undefined, targetHandle: e.targetHandle ?? undefined,
    })),
  }
}

function loadFlow(flow: FlowDefinition) {
  const loaded: Node[] = []
  for (const n of flow.nodes) {
    const def = props.definitions.get(n.nodeKey)
    if (!def) continue
    loaded.push({
      id: n.id,
      type: def.type.toLowerCase(),
      position: { x: n.x, y: n.y },
      data: {
        nodeKey: def.key, name: n.name || def.name, description: n.description,
        config: n.config ?? {}, def,
      } satisfies FlowNodeData,
    })
  }
  nodes.value = loaded
  edges.value = flow.edges.map((e) => ({
    id: e.id, source: e.source, target: e.target,
    sourceHandle: e.sourceHandle ?? undefined, targetHandle: e.targetHandle ?? undefined,
  }))
}

function clear() { nodes.value = []; edges.value = [] }

function updateNodeData(id: string, patch: Partial<FlowNodeData>) {
  nodes.value = nodes.value.map((n) =>
    n.id === id ? { ...n, data: { ...(n.data as FlowNodeData), ...patch } } : n
  )
}

function applyResults(result: ExecutionResult) {
  nodes.value = nodes.value.map((n) => {
    const d = n.data as FlowNodeData
    const r = result.nodeResults[n.id]
    if (!r) return n
    return {
      ...n,
      data: {
        ...d,
        status: r.status === 'SUCCESS' ? 'success' : r.status === 'ERROR' ? 'error' : 'skipped',
        outputPreview: r.outputPreview,
        error: r.error ?? undefined,
        durationMs: r.durationMs,
      },
    }
  })
}

function clearResults() {
  nodes.value = nodes.value.map((n) => {
    const d = { ...(n.data as FlowNodeData) }
    delete d.status; delete d.outputPreview; delete d.error; delete d.durationMs
    return { ...n, data: d }
  })
}

defineExpose({ addNodeByKey, getFlowData, loadFlow, clear, updateNodeData, applyResults, clearResults })
</script>

<template>
  <div class="canvas-wrap" @drop="onDrop" @dragover.prevent>
    <VueFlow
      id="main-flow"
      v-model:nodes="nodes"
      v-model:edges="edges"
      :node-types="nodeTypes"
      :delete-key-code="['Delete', 'Backspace']"
      fit-view-on-init
      class="flow-canvas"
    >
      <Background />
      <Controls />
      <MiniMap />
    </VueFlow>
  </div>
</template>

.canvas-wrap { flex: 1; position: relative; min-height: 0; }
.flow-canvas { width: 100%; height: 100%; }
</style>
```

```vue
  await api.deleteFlowApi(currentFlowId.value)

  newFlow()

  const data = canvasRef.value.getFlowData(flowName.value, currentFlowId.value, flowDescription.value)
  const saved = currentFlowId.value

  execution.value = null

    running.value = false
  }
}

      ...selectedNode.value,
      data: { ...(selectedNode.value.data as FlowNodeData), ...patch },

  }
```

## 四、把你现有的方法变成节点

在你的任意 Spring Bean 上加注解即可，启动后自动出现在左侧节点库：

```java
@Service
public class MyBizService {

    // 单输入单输出：第一个参数 = 上游数据（Map<输入端口名, 数据>）
    @FlowNode(key = "compute.my-score", name = "评分计算", type = NodeType.COMPUTE,
              inputs = "in", outputs = "out", description = "复用现有评分逻辑")
    public Object score(Map<String, Object> in) {
        List<?> rows = (List<?>) in.get("in");
        return doMyOldScoreLogic(rows);   // 直接调你原来的方法
    }

    // 需要页面配置参数时：加第二个参数 + params 声明（前端自动渲染表单）
    @FlowNode(key = "compute.my-rule", name = "规则计算", type = NodeType.COMPUTE,
              inputs = "in", outputs = "out",
              params = { @NodeParam(name = "threshold", description = "阈值", defaultValue = "60") })
    public Object rule(Map<String, Object> in, Map<String, Object> config) {
        double threshold = Double.parseDouble(String.valueOf(config.get("threshold")));
        ...
    }

    // 多输出：返回 Map<端口名, 数据>，端口用 outputs 声明
    @FlowNode(key = "compute.my-split", name = "黑白名单分流", type = NodeType.COMPUTE,
              inputs = "in", outputs = { "white", "black" })
    public Object split(Map<String, Object> in) {
        return Map.of("white", whiteList, "black", blackList);
    }
}
```

约定总结：
- **输入节点**：方法收到的是节点配置 Map，返回值就是数据源。
- **计算节点**：收到 `Map<输入端口名, 上游数据>`，返回值走 `out` 端口；多输出返回 `Map<端口名, 数据>`。
- **输出节点**：收到的 Map 里有 `value`（上游数据）+ 节点配置。

## 五、下一步扩展建议（MVP 之后）

1. **输入/输出扩展**：照着 `input.json` 加 `input.excel`（EasyExcel）、`input.http`（RestClient）、`input.db`（JdbcTemplate），只需新增带注解的方法。
2. **持久化**：把 `InMemoryFlowRepository` 换成 JPA 实现（`nodes/edges` 用 JSON 列存），接口不变。
3. **执行体验**：执行改异步 + SSE 推送，节点逐个点亮；加执行历史记录表。
4. **可用性**：连线校验（端口类型匹配）、撤销重做、节点分组/子流程、参数校验。
5. **可视化现有逻辑**：写一个导出器，把你现有代码里的计算链路按 `FlowDefinition` 结构导出成 JSON，导入即渲染。

有需要的话，下一步我可以帮你把 Excel/HTTP/DB 输入节点、数据库持久化，或者"现有代码链路导出成 flow"的导出器实现出来。
