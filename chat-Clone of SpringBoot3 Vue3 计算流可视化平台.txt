我有一套很复杂的计算逻辑，需要调用很多个方法，我想可视化一下。想着弄一个计算引擎平台。可以展示节点，拖动节点连线，执行flow，新建flow，保存flow，节点可以修改名称，描述等。然后节点主要有三个类型，输入 输出 计算。输入节点可以支持json，excel，htttp db等 现在最小版本只需要json。输出节点和输入节点类似。计算节点可以有多个输入节点，也可以有多个输出节点。最好弄一个注解，可以把现有的方法直接变成节点。左侧展示节点，中间展示画布，点击画布上节点，可以修改节点一些配置，比如参数，名称，描述等。节点输入输出连线都是一个端口，但是可以分出不同的线来连接其他节点。我用的springboot3 vue3 typescript。这个计算平台可以可视化现有的一套flow计算逻辑，也可以根据节点新建flow。先帮我实现一个最小版本。

# Flow 计算引擎平台 — 最小可用版本

下面给你一套完整可跑的最小版本，技术栈完全按你的要求：**Spring Boot 3 + Vue 3 + TypeScript**。

## 一、整体设计

**核心思路：**

1. **图数据结构**：画布本质是一张图 `{ nodes, edges }`，前端用 [Vue Flow](https://vueflow.dev/) 渲染，后端存同一份 JSON，执行时解析它
2. **注解驱动节点**：`@FlowNode` 注解打在任意 Spring Bean 的方法上，启动时自动扫描注册成节点，左侧节点库自动出现
3. **执行引擎**：拓扑排序（Kahn）→ 按序执行 → 上游输出沿边流向下游输入，天然支持环检测、一输入多输出、多输入汇聚
4. **单端口多连线**：节点只有一个输入/输出端口，Vue Flow 原生支持一个端口拉出任意多条边

**参数注入规则**（注解方法签名很灵活）：

| 方法参数类型 | 引擎注入的内容 |
|---|---|
| `Map<String,Object>` | 节点在画布上配置的参数 |
| `List<Object>` | 所有上游节点的输出列表 |
| `NodeContext` | 完整上下文（id/名称/配置/输入） |
| 其他类型 | 第一个上游输入 |

### registry/NodeRegistry.java —— 注解扫描与反射调用

```java
package com.example.flowengine.registry;

import com.example.flowengine.annotation.ConfigField;
import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.engine.NodeContext;
import com.example.flowengine.model.NodeDefinition;
import com.example.flowengine.model.NodeDefinition.ConfigFieldDef;
import jakarta.annotation.PostConstruct;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.context.ApplicationContext;
import org.springframework.stereotype.Component;
import org.springframework.util.ClassUtils;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Modifier;
import java.util.*;

@Component
public class NodeRegistry {

    private static final Logger log = LoggerFactory.getLogger(NodeRegistry.class);

    private record RegisteredNode(NodeDefinition definition, Object bean, Method method) {}

    private final ApplicationContext applicationContext;
    private final Map<String, RegisteredNode> nodes = new LinkedHashMap<>();

    public NodeRegistry(ApplicationContext applicationContext) {
        this.applicationContext = applicationContext;
    }

    /** 启动时扫描所有 Bean 方法上的 @FlowNode */
    @PostConstruct
    void scan() {
        for (String beanName : applicationContext.getBeanDefinitionNames()) {
            Object bean;
            try {
                bean = applicationContext.getBean(beanName);
            } catch (Exception e) {
                continue;
            }
            Class<?> targetClass = ClassUtils.getUserClass(bean.getClass());
            if (skip(targetClass)) continue;

            for (Method method : targetClass.getMethods()) {
                FlowNode ann = method.getAnnotation(FlowNode.class);
                if (ann == null || Modifier.isStatic(method.getModifiers())) continue;

                String id = beanName + "." + method.getName();
                if (nodes.containsKey(id)) {
                    throw new IllegalStateException("节点ID重复: " + id);
                }
                method.setAccessible(true);

                List<ConfigFieldDef> fields = Arrays.stream(ann.fields())
                        .map(f -> new ConfigFieldDef(
                                f.key(),
                                f.label().isEmpty() ? f.key() : f.label(),
                                f.type().name().toLowerCase(),
                                f.defaultValue()))
                        .toList();

                NodeDefinition def = new NodeDefinition(
                        id, ann.name(), ann.description(), ann.type(), ann.category(), fields);
                nodes.put(id, new RegisteredNode(def, bean, method));
                log.info("注册流程节点: {} ({})", ann.name(), id);
            }
        }
    }

    private boolean skip(Class<?> clazz) {
        String name = clazz.getName();
        return name.startsWith("org.springframework") || name.startsWith("java.")
                || name.startsWith("jdk.") || name.startsWith("com.sun")
                || name.contains("$$SpringCGLIB$$");
    }

    public List<NodeDefinition> getDefinitions() {
        return nodes.values().stream().map(RegisteredNode::definition).toList();
    }

    public NodeDefinition getDefinition(String id) {
        RegisteredNode n = nodes.get(id);
        return n == null ? null : n.definition();
    }

    /** 反射执行节点方法 */
    public Object execute(String defId, NodeContext context) throws Exception {
        RegisteredNode n = nodes.get(defId);
        if (n == null) throw new IllegalArgumentException("未找到节点定义: " + defId);
        try {
            return n.method().invoke(n.bean(), resolveArgs(n.method(), context));
        } catch (InvocationTargetException e) {
            throw e.getCause() instanceof Exception ex ? ex : e;
        }
    }

    /** 按参数类型自动注入：Map→配置，List→全部上游输入，其他→第一个上游输入 */
    private Object[] resolveArgs(Method method, NodeContext ctx) {
        Class<?>[] types = method.getParameterTypes();
        Object[] args = new Object[types.length];
        for (int i = 0; i < types.length; i++) {
            Class<?> t = types[i];
            if (NodeContext.class.isAssignableFrom(t)) args[i] = ctx;
            else if (Map.class.isAssignableFrom(t)) args[i] = ctx.config() == null ? Map.of() : ctx.config();
            else if (List.class.isAssignableFrom(t)) args[i] = ctx.inputs() == null ? List.of() : ctx.inputs();
            else args[i] = (ctx.inputs() == null || ctx.inputs().isEmpty()) ? null : ctx.inputs().get(0);
        }
        return args;
    }
}
```

### engine/FlowExecutionEngine.java —— 执行引擎

```java
package com.example.flowengine.engine;

import com.example.flowengine.model.*;
import com.example.flowengine.registry.NodeRegistry;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.stream.Collectors;

@Service
public class FlowExecutionEngine {

    private final NodeRegistry registry;

    public FlowExecutionEngine(NodeRegistry registry) {
        this.registry = registry;
    }

    public record NodeTrace(String nodeId, String nodeName, String defName, String status,
                            long durationMs, Object output, String error) {}

    public record ExecutionResult(boolean success, String error, List<NodeTrace> traces,
                                  Map<String, Object> outputs, long durationMs) {}

    public ExecutionResult execute(FlowGraph graph) {
        long start = System.currentTimeMillis();
        List<GraphNode> nodes = graph == null || graph.nodes() == null ? List.of() : graph.nodes();
        List<GraphEdge> edges = graph == null || graph.edges() == null ? List.of() : graph.edges();
        List<NodeTrace> traces = new ArrayList<>();

        if (nodes.isEmpty()) {
            return new ExecutionResult(false, "流程中没有节点", traces, Map.of(), 0);
        }

        Map<String, GraphNode> nodeById = nodes.stream()
                .collect(Collectors.toMap(GraphNode::id, n -> n));
        for (GraphEdge e : edges) {
            if (!nodeById.containsKey(e.source()) || !nodeById.containsKey(e.target())) {
                return new ExecutionResult(false, "连线引用了不存在的节点: " + e.id(), traces, Map.of(), 0);
            }
        }

        // 邻接关系 + 入度
        Map<String, List<String>> incoming = new HashMap<>();
        Map<String, Integer> indegree = new HashMap<>();
        nodes.forEach(n -> indegree.put(n.id(), 0));
        for (GraphEdge e : edges) {
            incoming.computeIfAbsent(e.target(), k -> new ArrayList<>()).add(e.source());
            indegree.merge(e.target(), 1, Integer::sum);
        }

        // Kahn 拓扑排序
        Deque<String> queue = new ArrayDeque<>();
        nodes.forEach(n -> { if (indegree.get(n.id()) == 0) queue.add(n.id()); });
        List<String> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            String id = queue.poll();
            order.add(id);
            for (GraphEdge e : edges) {
                if (e.source().equals(id) && indegree.merge(e.target(), -1, Integer::sum) == 0) {
                    queue.add(e.target());
                }
            }
        }
        if (order.size() != nodes.size()) {
            return new ExecutionResult(false, "流程中存在循环依赖，请检查连线", traces, Map.of(), 0);
        }

        Map<String, Object> outputs = new HashMap<>();
        Map<String, String> status = new HashMap<>();
        Map<String, Object> finalOutputs = new LinkedHashMap<>();
        boolean allSuccess = true;

        for (String id : order) {
            GraphNode node = nodeById.get(id);
            FlowNodeData data = node.data();
            String nodeName = data != null && data.name() != null ? data.name() : id;
            String defName = data != null ? data.defName() : null;
            List<String> sources = incoming.getOrDefault(id, List.of());

            // 上游失败则跳过
            if (!sources.isEmpty() && sources.stream().anyMatch(s -> !"SUCCESS".equals(status.get(s)))) {
                status.put(id, "SKIPPED");
                traces.add(new NodeTrace(id, nodeName, defName, "SKIPPED", 0, null, "上游节点未成功执行"));
                allSuccess = false;
                continue;
            }

            NodeDefinition def = data == null ? null : registry.getDefinition(data.defId());
            if (def == null) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED", 0, null,
                        "未找到节点定义: " + (data == null ? "?" : data.defId())));
                continue;
            }

            List<Object> inputs = sources.stream().map(outputs::get).collect(Collectors.toList());
            long t0 = System.currentTimeMillis();
            try {
                Map<String, Object> config = data.config() == null ? Map.of() : data.config();
                Object result = registry.execute(def.id(), new NodeContext(id, nodeName, config, inputs));
                outputs.put(id, result);
                status.put(id, "SUCCESS");
                traces.add(new NodeTrace(id, nodeName, defName, "SUCCESS",
                        System.currentTimeMillis() - t0, result, null));
                if (def.type() == NodeType.OUTPUT) {
                    finalOutputs.put(nodeName, result);
                }
            } catch (Exception ex) {
                status.put(id, "FAILED");
                allSuccess = false;
                traces.add(new NodeTrace(id, nodeName, defName, "FAILED",
                        System.currentTimeMillis() - t0, null, message(ex)));
            }
        }

        return new ExecutionResult(allSuccess, allSuccess ? null : "部分节点执行失败",
                traces, finalOutputs, System.currentTimeMillis() - start);
    }

    private String message(Throwable t) {
        return t.getMessage() == null ? t.getClass().getSimpleName() : t.getMessage();
    }
}
```

```java
package com.example.flowengine.nodes;

import com.example.flowengine.annotation.ConfigField;
import com.example.flowengine.annotation.FlowNode;
import com.example.flowengine.model.NodeType;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

@Component
public class BuiltinNodes {

    private final ObjectMapper objectMapper = new ObjectMapper();

    // ---------- 输入节点（最小版本只做 JSON，后续可加 Excel/HTTP/DB） ----------

    @FlowNode(name = "JSON输入", type = NodeType.INPUT, category = "输入",
            description = "将配置的 JSON 文本解析为数据对象",
            fields = @ConfigField(key = "jsonText", label = "JSON内容",
                    type = ConfigField.FieldType.TEXTAREA, defaultValue = "{}"))
    public Object jsonInput(Map<String, Object> config) throws Exception {
        String text = asString(config.get("jsonText"));
        if (text == null || text.isBlank()) return Map.of();
        return objectMapper.readValue(text, Object.class);
    }

    // ---------- 输出节点 ----------

    @FlowNode(name = "JSON输出", type = NodeType.OUTPUT, category = "输出",
            description = "将上游结果序列化为 JSON 字符串")
    public Object jsonOutput(List<Object> inputs) throws Exception {
        Object payload = inputs.size() == 1 ? inputs.get(0) : inputs;
        return objectMapper.writerWithDefaultPrettyPrinter().writeValueAsString(payload);
    }

    // ---------- 计算节点 ----------

    @FlowNode(name = "字段提取", category = "计算",
            description = "从 Map 或 Map 列表中按 key 提取字段",
            fields = @ConfigField(key = "field", label = "字段名"))
    public Object extractField(List<Object> inputs, Map<String, Object> config) {
        String field = asString(config.get("field"));
        if (field == null || field.isBlank()) throw new IllegalArgumentException("缺少参数 field");
        List<Object> result = new ArrayList<>();
        inputs.forEach(in -> collect(in, field, result));
        return result.size() == 1 ? result.get(0) : result;
    }

    private void collect(Object value, String field, List<Object> out) {
        if (value instanceof Map<?, ?> map) out.add(map.get(field));
        else if (value instanceof List<?> list) list.forEach(o -> collect(o, field, out));
    }

    @FlowNode(name = "数值求和", category = "计算", description = "对所有输入中的数值求和（支持多个输入汇聚）")
    public Object sum(List<Object> inputs) {
        double[] total = {0};
        inputs.forEach(v -> sumInto(v, total));
        return total[0] % 1 == 0 ? (long) total[0] : total[0];
    }

    private void sumInto(Object value, double[] total) {
        if (value instanceof Number n) total[0] += n.doubleValue();
        else if (value instanceof List<?> list) list.forEach(o -> sumInto(o, total));
        else if (value instanceof Map<?, ?> map) map.values().forEach(v -> sumInto(v, total));
    }

    @FlowNode(name = "常量", category = "计算", description = "无需输入，输出一个配置的常量值",
            fields = @ConfigField(key = "value", label = "常量值",
                    type = ConfigField.FieldType.NUMBER, defaultValue = "0"))
    public Object constant(Map<String, Object> config) {
        return config.get("value");
    }

    private String asString(Object o) { return o == null ? null : String.valueOf(o); }
}
```

### repository/FlowRepository.java —— 内存存储 + 种子数据

```java
package com.example.flowengine.repository;

import com.example.flowengine.model.*;
import org.springframework.stereotype.Repository;

import java.time.Instant;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

/** 最小版本用内存存储，后续可替换为 JPA + 数据库 */
@Repository
public class FlowRepository {

    private final Map<String, Flow> store = new ConcurrentHashMap<>();

    public FlowRepository() {
        seed();
    }

    public List<Flow> findAll() {
        return store.values().stream()
                .sorted(Comparator.comparing(Flow::getUpdatedAt).reversed()).toList();
    }

    public Optional<Flow> findById(String id) { return Optional.ofNullable(store.get(id)); }

    public Flow save(Flow flow) {
        flow.setUpdatedAt(Instant.now());
        store.put(flow.getId(), flow);
        return flow;
    }

    public void delete(String id) { store.remove(id); }

    /** 种子示例：订单金额汇总（含多输入汇聚演示） */
    private void seed() {
        Map<String, Object> jsonConfig = new HashMap<>();
        jsonConfig.put("jsonText", """
                {
                  "order": "DEMO-001",
                  "items": [
                    {"name": "键盘", "amount": 199},
                    {"name": "鼠标", "amount": 99},
                    {"name": "显示器", "amount": 1299}
                  ]
                }
                """);

        // 注意：defId = beanName + "." + 方法名
        FlowGraph graph = new FlowGraph(List.of(
                node("n1", NodeType.INPUT,   40, 180, data("builtinNodes.jsonInput",   NodeType.INPUT,   "JSON输入", "订单数据", "演示输入", jsonConfig)),
                node("n2", NodeType.COMPUTE, 280, 80,  data("builtinNodes.extractField", NodeType.COMPUTE, "字段提取", "提取items", "", Map.of("field", "items"))),
                node("n3", NodeType.COMPUTE, 520, 80,  data("builtinNodes.extractField", NodeType.COMPUTE, "字段提取", "提取amount", "", Map.of("field", "amount"))),
                node("n5", NodeType.COMPUTE, 280, 320, data("builtinNodes.constant",   NodeType.COMPUTE, "常量", "运费", "", Map.of("value", 10))),
                node("n4", NodeType.COMPUTE, 760, 200, data("builtinNodes.sum",        NodeType.COMPUTE, "数值求和", "总金额", "", Map.of())),
                node("n6", NodeType.OUTPUT,  1000, 200, data("builtinNodes.jsonOutput", NodeType.OUTPUT, "JSON输出", "结果输出", "", Map.of()))
        ), List.of(
                edge("n1", "n2"), edge("n2", "n3"), edge("n3", "n4"),
                edge("n5", "n4"), edge("n4", "n6")
        ));

        Flow flow = new Flow();
        flow.setId("demo");
        flow.setName("示例：订单金额汇总");
        flow.setDescription("JSON输入 → 字段提取 → 求和（与运费常量汇聚）→ JSON输出");
        flow.setGraph(graph);
        flow.setUpdatedAt(Instant.now());
        store.put(flow.getId(), flow);
    }

    private static GraphNode node(String id, NodeType type, double x, double y, FlowNodeData data) {
        return new GraphNode(id, "flow-node", data, Map.of("x", x, "y", y));
    }

    private static FlowNodeData data(String defId, NodeType type, String defName,
                                     String name, String description, Map<String, Object> config) {
        return new FlowNodeData(defId, type, defName, name, description, config);
    }

    private static GraphEdge edge(String source, String target) {
```

```java
package com.example.flowengine.service;

import com.example.flowengine.model.Flow;
import com.example.flowengine.model.FlowGraph;
import com.example.flowengine.repository.FlowRepository;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.web.server.ResponseStatusException;

import java.time.Instant;
import java.util.List;
import java.util.UUID;

@Service
public class FlowService {

    private final FlowRepository repository;

    public FlowService(FlowRepository repository) {
        this.repository = repository;
    }

    public record FlowSummary(String id, String name, String description, Instant updatedAt) {}

    public List<FlowSummary> list() {
        return repository.findAll().stream()
                .map(f -> new FlowSummary(f.getId(), f.getName(), f.getDescription(), f.getUpdatedAt()))
                .toList();
    }

    public Flow get(String id) {
        return repository.findById(id)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "流程不存在: " + id));
    }

    public Flow create(String name, String description, FlowGraph graph) {
        Flow flow = new Flow();
        flow.setId(UUID.randomUUID().toString().replace("-", "").substring(0, 12));
        flow.setName(name == null || name.isBlank() ? "未命名流程" : name);
        flow.setDescription(description);
        flow.setGraph(graph == null ? new FlowGraph(List.of(), List.of()) : graph);
        return repository.save(flow);
    }

    public Flow update(String id, String name, String description, FlowGraph graph) {
        Flow flow = get(id);
        if (name != null && !name.isBlank()) flow.setName(name);
        flow.setDescription(description);
        if (graph != null) flow.setGraph(graph);
        return repository.save(flow);
    }

    public void delete(String id) {
        get(id);
        repository.delete(id);
    }
}
```

```vue
<script setup lang="ts">
import { nextTick } from 'vue'
import { VueFlow, useVueFlow, type Connection, type GraphNode } from '@vue-flow/core'
import { Background } from '@vue-flow/background'
import { Controls } from '@vue-flow/controls'
import FlowNode from './FlowNode.vue'
import type { FlowGraph, FlowNodeData, NodeDefinition } from '../types'

const emit = defineEmits<{ (e: 'node-select', node: GraphNode | null): void }>()

const nodeTypes = { 'flow-node': FlowNode }

const {
  addNodes, addEdges, setNodes, setEdges, removeNodes,
  getNodes, getEdges, screenToFlowCoordinate, fitView
} = useVueFlow()

let seq = 0

/** 从节点定义创建画布节点 */
function addNode(def: NodeDefinition, at?: { x: number; y: number }) {
  const id = `n_${Date.now()}_${seq++}`
  const config: Record<string, any> = {}
  def.fields?.forEach(f => {
    config[f.key] = f.defaultValue ?? ''
  })
  const data: FlowNodeData = {
    defId: def.id,
    nodeType: def.type,
    defName: def.name,
    name: def.name,
    description: def.description,
    config
  }
  addNodes({
    id,
    type: 'flow-node',
    position: at ?? { x: 220 + (seq % 6) * 36, y: 140 + (seq % 6) * 36 },
    data
  })
}

function onDrop(event: DragEvent) {
  const raw = event.dataTransfer?.getData('application/flow-node')
  if (!raw) return
  const def: NodeDefinition = JSON.parse(raw)
  const position = screenToFlowCoordinate({ x: event.clientX, y: event.clientY })
  addNode(def, position)
}

function onConnect(conn: Connection) {
  const dup = getEdges.value.some(e => e.source === conn.source && e.target === conn.target)
  if (dup || !conn.source || !conn.target) return
  addEdges({
    id: `e_${conn.source}_${conn.target}_${Date.now()}`,
    source: conn.source,
    target: conn.target,
    type: 'smoothstep'
  })
}

function onSelectionChange(params: { nodes: GraphNode[] }) {
  emit('node-select', params.nodes.length ? params.nodes[0] : null)
}

/** 序列化当前画布 */
function getGraph(): FlowGraph {
  return {
    nodes: getNodes.value.map(n => ({
      id: n.id,
      type: n.type,
      position: { x: n.position.x, y: n.position.y },
      data: n.data
    })),
    edges: getEdges.value.map(e => ({ id: e.id, source: e.source, target: e.target }))
  }
}

function loadGraph(graph: FlowGraph) {
  setNodes((graph?.nodes ?? []).map(n => ({
    ...n,
    type: 'flow-node',
    data: { ...n.data, config: n.data?.config ?? {} }
  })))
  setEdges((graph?.edges ?? []).map(e => ({ ...e, type: 'smoothstep' })))
  nextTick(() => fitView({ padding: 0.2 }))
}

function clear() {
  setNodes([])
  setEdges([])
}

function applyStatus(map: Record<string, 'success' | 'failed' | 'skipped'>) {
  getNodes.value.forEach(n => {
    ;(n.data as FlowNodeData).status = map[n.id]
  })
}

function clearStatus() {
  getNodes.value.forEach(n => {
    delete (n.data as FlowNodeData).status
  })
```

## 五、如何把你现有的方法接入成节点

这是这个方案最核心的部分——**在现有方法上加一个注解即可**：

```java
@Service
public class RiskRules {

    @FlowNode(
        name = "风控评分",
        category = "风控",
        description = "根据订单数据计算风控分",
        fields = @ConfigField(key = "threshold", label = "阈值",
                type = ConfigField.FieldType.NUMBER, defaultValue = "80")
    )
    public Object score(List<Object> inputs, Map<String, Object> config) {
        double threshold = Double.parseDouble(String.valueOf(config.get("threshold")));
        // ... 你现有的计算逻辑，原封不动
        return result;
    }
}
```

重启后端，左侧节点库自动出现「风控评分」，画布上可配置阈值参数。规则回顾：

- 参数里写 `Map` → 收到画布上配置的参数
- 参数里写 `List` → 收到所有上游节点的输出
- 注解的 `fields` → 前端自动渲染配置表单，不用写一行前端代码
- 节点 id 规则为 `beanName.方法名`，需要改名可用 `@Component("xxx")`

## 修复方案：直接替换 FlowCanvas.vue（全版本兼容）

我把坐标转换改成用 `viewport` 手动计算，**不依赖任何版本的方法名**，新旧版都能跑。整个文件替换成这个：

```vue
<script setup lang="ts">
import { nextTick } from 'vue'
import { VueFlow, useVueFlow, type Connection, type GraphNode } from '@vue-flow/core'
import { Background } from '@vue-flow/background'
import { Controls } from '@vue-flow/controls'
import FlowNode from './FlowNode.vue'
import type { FlowGraph, FlowNodeData, NodeDefinition } from '../types'

const emit = defineEmits<{ (e: 'node-select', node: GraphNode | null): void }>()

const nodeTypes = { 'flow-node': FlowNode }

const {
  addNodes, addEdges, setNodes, setEdges, removeNodes,
  getNodes, getEdges, fitView, viewport
} = useVueFlow()

let seq = 0

/**
 * 屏幕坐标 → 画布坐标。
 * 用 viewport 数学换算，兼容所有 @vue-flow/core 版本，
 * 不依赖 screenToFlowCoordinate（新版）或 project（老版）
 */
function toFlowCoordinate(clientX: number, clientY: number) {
  const el = document.querySelector('.vue-flow') as HTMLElement | null
  const rect = el?.getBoundingClientRect()
  if (!rect) return { x: clientX, y: clientY }
  const v = viewport.value
  return {
    x: (clientX - rect.left - v.x) / v.zoom,
    y: (clientY - rect.top - v.y) / v.zoom
  }
}

function addNode(def: NodeDefinition, at?: { x: number; y: number }) {
  const id = `n_${Date.now()}_${seq++}`
  const config: Record<string, any> = {}
  def.fields?.forEach(f => {
    config[f.key] = f.defaultValue ?? ''
  })
  const data: FlowNodeData = {
    defId: def.id,
    nodeType: def.type,
    defName: def.name,
    name: def.name,
    description: def.description,
    config
  }
  addNodes({
    id,
    type: 'flow-node',
    position: at ?? { x: 220 + (seq % 6) * 36, y: 140 + (seq % 6) * 36 },
    data
  })
}

function onDragOver(event: DragEvent) {
  event.preventDefault()
  if (event.dataTransfer) event.dataTransfer.dropEffect = 'move'
}

function onDrop(event: DragEvent) {
  event.preventDefault()
  const raw = event.dataTransfer?.getData('application/flow-node')
  if (!raw) return
  const def: NodeDefinition = JSON.parse(raw)
  addNode(def, toFlowCoordinate(event.clientX, event.clientY))
}

function onConnect(conn: Connection) {
  const dup = getEdges.value.some(e => e.source === conn.source && e.target === conn.target)
  if (dup || !conn.source || !conn.target) return
  addEdges({
    id: `e_${conn.source}_${conn.target}_${Date.now()}`,
    source: conn.source,
    target: conn.target,
    type: 'smoothstep'
  })
}

function onSelectionChange(params: { nodes: GraphNode[] }) {
  emit('node-select', params.nodes.length ? params.nodes[0] : null)
}

function getGraph(): FlowGraph {
  return {
    nodes: getNodes.value.map(n => ({
      id: n.id,
      type: n.type,
      position: { x: n.position.x, y: n.position.y },
      data: n.data
    })),
    edges: getEdges.value.map(e => ({ id: e.id, source: e.source, target: e.target }))
  }
}

function loadGraph(graph: FlowGraph) {
  setNodes((graph?.nodes ?? []).map(n => ({
    ...n,
    type: 'flow-node',
    data: { ...n.data, config: n.data?.config ?? {} }
  })))
  setEdges((graph?.edges ?? []).map(e => ({ ...e, type: 'smoothstep' })))
  nextTick(() => fitView({ padding: 0.2 }))
}

function clear() {
  setNodes([])
  setEdges([])
}

function applyStatus(map: Record<string, 'success' | 'failed' | 'skipped'>) {
  getNodes.value.forEach(n => {
    ;(n.data as FlowNodeData).status = map[n.id]
  })
}

function clearStatus() {
  getNodes.value.forEach(n => {
    delete (n.data as FlowNodeData).status
  })
}

function deleteNode(id: string) {
  removeNodes(id)
}

defineExpose({ addNode, getGraph, loadGraph, clear, applyStatus, clearStatus, deleteNode })
</script>
```
